# 🔧 Path 2: IT Support & System Administration

**Help people with tech problems and manage computer systems.**

---

## 🎯 What Do IT Support & Sysadmins Do?

IT professionals keep businesses running by:
- Fixing computer and network problems
- Setting up new employees with equipment and accounts
- Managing servers and cloud services
- Ensuring security and backups
- Helping users with software issues
- Maintaining hardware and infrastructure

**You're the hero who saves the day when technology breaks!**

---

## 🔧 Key Areas

### 1. IT Support / Help Desk
**First line of defense - helping users directly**

- Troubleshooting hardware/software issues
- Setting up computers and peripherals
- Password resets and account management
- Installing and configuring software
- Customer service and communication

**You'll enjoy this if:** You like helping people and solving varied problems

---

### 2. System Administration
**Managing servers and infrastructure**

- Server setup and maintenance (Windows Server, Linux)
- User account management (Active Directory)
- Network configuration
- Backup and disaster recovery
- Security patches and updates
- Monitoring system performance

**You'll enjoy this if:** You like deep technical work and automation

---

### 3. Network Administration
**Keeping everything connected**

- Router and switch configuration
- WiFi setup and troubleshooting
- Firewall management
- VPN configuration
- Network monitoring and security

**You'll enjoy this if:** You're fascinated by how data moves around

---

## 📚 Learning Roadmap

### Phase 1: Foundations (4-6 weeks)

**Build on what you learned in Prerequisites:**

1. **Computer Hardware Basics**
   - CPU, RAM, storage (HDD/SSD)
   - Motherboards and components
   - Peripherals (printers, scanners, monitors)
   - Basic troubleshooting

2. **Operating Systems**
   - Windows 10/11 (deep dive)
   - macOS basics
   - File systems (NTFS, APFS, ext4)
   - System settings and configurations

3. **Basic Networking**
   - IP addresses (IPv4)
   - DHCP and DNS (what they do)
   - Routers vs. switches
   - WiFi standards
   - Basic troubleshooting (ping, tracert)

✅ **Project:** Build a home lab (old computer or virtual machines)

---

### Phase 2: Core IT Skills (8-12 weeks)

1. **Windows Administration**
   - Active Directory (user accounts, groups)
   - Group Policy
   - Windows Server basics
   - PowerShell basics

2. **Linux Basics** (CRITICAL for sysadmin)
   - Command line navigation
   - File permissions
   - Package management
   - Basic services (web server, SSH)
   - User management

3. **Networking Fundamentals**
   - OSI model (conceptual understanding)
   - Subnetting basics
   - VLANs
   - Common protocols (HTTP, HTTPS, FTP, SSH, SMTP)
   - Network troubleshooting tools

4. **Security Basics**
   - Antivirus and anti-malware
   - Firewalls
   - Encryption basics
   - Best practices for passwords
   - Social engineering awareness

✅ **Project:** Set up a small network with multiple VMs

---

### Phase 3: Intermediate Skills (12-16 weeks)

1. **Advanced Windows Server**
   - Domain Controllers
   - DNS and DHCP servers
   - File servers and permissions
   - Remote Desktop Services

2. **Advanced Linux**
   - Shell scripting (bash)
   - Cron jobs (scheduled tasks)
   - Log analysis
   - Service management (systemd)
   - LAMP/LEMP stacks

3. **Virtualization**
   - VMware or Hyper-V
   - Creating and managing VMs
   - Snapshots and templates
   - Resource allocation

4. **Cloud Basics**
   - AWS, Azure, or Google Cloud fundamentals
   - Virtual machines in the cloud
   - Cloud storage
   - Identity management

5. **Backup and Recovery**
   - Backup strategies (full, incremental, differential)
   - Backup software
   - Disaster recovery planning
   - Testing restores

✅ **Project:** Build a complete small business infrastructure in a lab

---

### Phase 4: Advanced Topics (Ongoing)

- Automation (PowerShell, Python, Ansible)
- Containerization (Docker basics)
- Monitoring tools (Nagios, PRTG, Zabbix)
- Advanced security (SIEM, IDS/IPS)
- ITIL framework (IT service management)
- Scripting for automation

✅ **Project:** Automate routine tasks in your lab

## ✅ How to Know You're Ready

You're ready for entry-level IT support when you can:

- Troubleshoot common Windows/Mac problems
- Explain basic networking concepts
- Comfortably use command line (PowerShell or bash)
- Set up and configure user accounts
- Understand security best practices
- Communicate technical issues to non-technical people
- Show initiative through home lab projects

## 💡 Tips for Breaking Into IT

### 1. Get Certified
A+ certification is the gold standard for entry-level IT jobs.

### 2. Build a Home Lab
Employers love seeing hands-on experience, even if it's at home.

### 3. Start at Help Desk
Most IT careers start here. It's tough but invaluable experience.

### 4. Document Everything
Keep a log of problems you've solved. Great for interviews!

### 5. Network (The Human Kind)
Join local IT meetups, LinkedIn groups, and online communities.

### 6. Consider Contract/Temp Work
Staffing agencies can place you in short-term IT roles.
