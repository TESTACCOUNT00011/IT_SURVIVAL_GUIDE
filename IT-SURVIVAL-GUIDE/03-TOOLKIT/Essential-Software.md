# Essential Toolkit

Software and extensions every beginner needs. Safe and free.

## Browser Extensions

- **uBlock Origin**: Block ads and malicious scripts.
- **Bitwarden**: Password manager. Generate unique passwords for every site.
- **Dark Reader**: Force dark mode on all websites.
- **Wappalyzer**: See what technologies a website uses.

## Core Software

- **VS Code**: Free code editor. Lightweight and powerful.
- **Git**: Version control. Install Git for Windows or use terminal on Mac/Linux.
- **Node.js**: JavaScript runtime (needed for many web tools).
- **Python 3**: Programming language for scripting and data.

## Communication

- **Discord**: For joining tech communities.
- **Zoom/Google Meet**: For interviews and meetings.
- **Slack**: Used by many companies for chat.

## Safety Rules

1. **Download from Official Sites Only**:
   - Do not click "Download" buttons on random blogs.
   - Go to `code.visualstudio.com`, `git-scm.com`, `python.org`.
2. **Avoid "Cracked" Software**: It often contains malware.
3. **Keep Updated**: Enable auto-updates for security patches.

> [!WARNING] Fake Download Buttons
> Search results often contain ads that look like download links. Look for the actual domain name in the URL.
