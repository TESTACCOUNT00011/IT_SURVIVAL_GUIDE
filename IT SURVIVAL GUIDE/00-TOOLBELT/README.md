# Essential Toolbelt

This guide lists the essential software every IT beginner needs. Install these first before diving deep into any path.

## Browser Setup

Your browser is your primary tool. Configure it properly.

### Required Extensions
- **uBlock Origin**: The only adblocker you need. Blocks ads, trackers, and malware domains.
- **Bitwarden**: Free, open-source password manager. Never reuse passwords again.
- **Dark Reader**: Reduces eye strain during late-night study sessions.

### Recommended Browsers
- **Firefox Developer Edition**: Great for web development with built-in tools.
- **Google Chrome**: Industry standard for testing website compatibility.
- **Brave**: Privacy-focused browser with built-in ad blocking.

## System Utilities

### Text Editors
- **VS Code**: The industry standard code editor. Lightweight, extensible, free.
- **Notepad++** (Windows): Fast, lightweight text editor for quick edits.
- **Sublime Text**: Fast, proprietary editor with excellent performance.

### Terminal Emulators
- **Windows Terminal** (Windows): Modern terminal with tabs and customization.
- **iTerm2** (macOS): Powerful replacement for the default macOS terminal.
- **Alacritty** (Cross-platform): GPU-accelerated terminal for performance.

### Virtualization
- **VirtualBox**: Run different operating systems in virtual machines. Essential for testing Linux or safe malware analysis.
- **WSL2** (Windows): Run Linux directly inside Windows without virtualization overhead.

## Communication Tools

- **Discord**: Where most tech communities hang out. Join servers related to your learning path.
- **Slack**: Used by many professional teams and some learning communities.
- **Zoom/Google Meet**: For online interviews, meetings, and study groups.

## Security Essentials

- **Malwarebytes**: On-demand malware scanner. Run this if you suspect an infection.
- **VeraCrypt**: Encrypt sensitive files and folders.
- **Authy/Google Authenticator**: Two-factor authentication for all your accounts.

## Installation Priority

1.  **Day 1**: Browser + uBlock Origin + Bitwarden
2.  **Day 2**: VS Code + Windows Terminal/iTerm2
3.  **Day 3**: VirtualBox/WSL2 + Discord

> [!TIP]
> Only download software from official websites. Avoid "download.com" or third-party installers as they often bundle malware.
