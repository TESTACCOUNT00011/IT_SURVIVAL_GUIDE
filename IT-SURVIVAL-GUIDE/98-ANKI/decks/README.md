## 📥 How to Download

1. Click on any deck link above
2. Download the `.apkg` file
3. Open Anki on your computer
4. Go to **File → Import**
5. Select the downloaded file
6. Start studying!

## 📝 Deck Format

All decks include:
- **Front**: Clear question or term
- **Back**: Concise answer with context
- **Tags**: Organized by topic for easy filtering
- **Examples**: Real-world applications where applicable
