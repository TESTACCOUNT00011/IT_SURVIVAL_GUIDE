# Path 5: Cloud Computing

## What You Will Do
Design and manage infrastructure on platforms like AWS, Azure, or Google Cloud. Instead of managing physical servers, you create virtual servers, databases, and networks through code.

## Day 1 Challenge
Create a free AWS account (Free Tier). Launch a small EC2 virtual machine. Connect to it via SSH. Turn it off so you are not charged.

## Learning Roadmap

### Phase 1: IT & Networking Foundations (Months 1-3)
**Warning**: Cloud is just someone else's computer. You need basics first.
- **Linux Command Line**: Essential for all cloud platforms.
- **Networking**: IP, Subnets, DNS, Firewalls, Load Balancers.
- **Virtualization**: What is a VM? Containers vs VMs.
- **Resource**: Linux Journey, Professor Messer Network+.

### Phase 2: Choose One Cloud Provider (Months 4-6)
Pick ONE to start. Concepts transfer later.
- **AWS**: Market leader, most services.
- **Azure**: Strong in enterprise, integrates with Microsoft.
- **GCP**: Strong in data and Kubernetes.
- **Focus Areas**: Compute (EC2), Storage (S3), Networking (VPC), IAM.
- **Resource**: Official Free Tier training (AWS Skill Builder, Microsoft Learn).

### Phase 3: Infrastructure as Code (Months 7-9)
Stop clicking in the console. Automate everything.
- **Terraform**: Industry standard IaC tool.
- **CloudFormation / ARM Templates**: Native options.
- **Version Control**: Git for your infrastructure code.
- **Resource**: HashiCorp Learn Terraform (Free).

### Phase 4: Containers & Orchestration (Months 10-12)
- **Docker**: Containerizing applications.
- **Kubernetes**: Managing containers at scale.
- **CI/CD Pipelines**: Automated deployment.
- **Resource**: Kubernetes.io documentation.

## Domain Goodies
- **AWS Skill Builder**: Official free training from Amazon.
- **Microsoft Learn**: Official free training from Microsoft.
- **Google Cloud Skills Boost**: Official free training from Google.
- **Cloud Resume Challenge**: Build a resume website using only cloud services.
- **A Cloud Guru / Linux Academy**: Paid but highly regarded (now part of Pluralsight).

## Certifications to Target
- **AWS Certified Cloud Practitioner**: Introductory.
- **AWS Solutions Architect Associate**: Gold standard entry cert.
- **Azure Administrator Associate (AZ-104)**.
- **Terraform Associate**: Vendor-neutral IaC cert.
