# 04 - AdBlock: Make the Internet Usable Again

## 🎯 Why Do You Need This?

Modern websites are COVERED in:
- Pop-up ads
- Auto-play videos with sound
- Trackers that follow you everywhere
- Fake "Download" buttons designed to trick you
- Annoying cookie banners (sometimes)

**This is not just annoying—it's dangerous.** Some ads contain malware.

An **AdBlocker** is a browser extension that blocks all this junk automatically.

---

## 🛡️ What Is an AdBlocker?

An adblocker is a small program that runs in your web browser and:
- Blocks visible ads (banners, pop-ups, video ads)
- Blocks hidden trackers (companies following what you do online)
- Makes websites load faster (less junk to download)
- Protects you from malicious ads

**It's like having a bouncer for your browser.**

## ✅ Recommended: uBlock Origin

**NOT** "uBlock" or "AdBlock Plus" — those are different (and worse).

You want **uBlock Origin** (by Raymond Hill). It's:
- ✅ Completely free
- ✅ Open source (transparent)
- ✅ Very effective
- ✅ Lightweight (doesn't slow your browser)
- ✅ No "acceptable ads" program (they don't sell out)

### How to Install uBlock Origin

#### For Google Chrome / Microsoft Edge / Brave:

1. Open Chrome Web Store: `https://chrome.google.com/webstore`
2. Search for: **"uBlock Origin"**
3. Look for the one by **Raymond Hill** (purple shield icon)
4. Click **"Add to Chrome"**
5. Click **"Add extension"** when prompted
6. Done! You'll see a little shield icon in your browser

#### For Firefox:

1. Open Firefox Add-ons: `https://addons.mozilla.org`
2. Search for: **"uBlock Origin"**
3. Look for the one by **Raymond Hill** (purple shield icon)
4. Click **"Add to Firefox"**
5. Click **"Add"** when prompted
6. Done!

#### For Safari (Mac):

Safari doesn't support uBlock Origin directly. Use:
- **AdGuard for Safari** (free version available)
- Or switch to Firefox/Chrome for better protection

## ⚙️ Basic Settings (Optional)

uBlock Origin works great out of the box, but here are some tweaks:

### Enable Additional Filter Lists

1. Click the uBlock Origin icon (shield)
2. Click the gears icon ⚙️ (Dashboard)
3. Go to the **"Filter lists"** tab
4. Expand **"Privacy"** section
5. Check these boxes:
   - [x] EasyPrivacy
   - [x] Fanboy's Enhanced Tracking List
6. Click **"Apply changes"** at the top

### Block Cookie Banners (European Users)

1. In Dashboard, go to **"Filter lists"**
2. Expand **"Annoyances"** section
3. Check:
   - [x] EasyList Cookie
   - [x] Fanboy's Cookie Monster
4. Click **"Apply changes"**

⚠️ **Warning:** Some websites might break with cookie banners blocked. You can disable this if needed.

## 🤔 Will This Break Websites?

Sometimes. Here's what to do:

### If a Website Doesn't Work:

1. Click the uBlock Origin icon
2. Click the big **Power button** 🔘 (temporarily disable)
3. Refresh the page
4. The site should work now
5. When you're done, click the power button again to re-enable

### If Only Part of a Site Breaks:

1. Click the uBlock Origin icon
2. Click the **Refresh** icon 🔄 (soft refresh)
3. This reloads filters without disabling completely

## 🚫 Common Mistakes

### ❌ Installing Multiple Adblockers
Don't install uBlock Origin AND AdBlock Plus AND AdGuard. They conflict and slow your browser.

**Just use uBlock Origin.** It's enough.

### ❌ Installing Fake Versions
Only install from official stores:
- Chrome Web Store
- Firefox Add-ons
- GitHub (for advanced users)

If it asks for weird permissions, it's fake.

### ❌ Paying for an Adblocker
**Adblockers should be FREE.** Don't pay. uBlock Origin is free and better than paid options.
