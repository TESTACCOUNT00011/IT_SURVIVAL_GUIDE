# Cybersecurity Communities

## Top Tier Communities

### Reddit
- **r/cybersecurity**: Industry news and career discussions.
- **r/AskNetsec**: Technical questions from professionals.
- **r/HowToHack**: Beginner questions (read rules, ethical only).
- **r/SecurityCareerAdvice**: Career path guidance.

### Discord Servers
- **TryHackMe Discord**: Active learners and mentors.
- **HackTheBox Discord**: Advanced penetration testing community.
- **NetSec Discord**: Professional network security discussions.
- **PicoCTF Discord**: Beginner-friendly CTF community.

### Specialized Forums
- **Wilders Security Forum**: Long-running security discussion.
- **Offensive Security Forums**: Official Kali Linux and OSCP forums.
- **Reddit r/BlueTeamSec**: Defensive security focus.

## Practice Platforms
- **OverTheWire**: Linux security wargames.
- **TryHackMe**: Guided learning paths and rooms.
- **HackTheBox**: Real-world machine exploitation.
- **PicoCTF**: High school/college level CTF competitions.
- **PortSwigger Web Security Academy**: Free web app hacking labs.

## Events & Meetups
- **DEF CON**: Largest hacker conference (Las Vegas + local chapters).
- **BSides**: Community-run conferences worldwide.
- **OWASP Chapters**: Local web security meetups.
- **CTFTime.org**: Calendar of Capture The Flag competitions.

> [!WARNING] Ethics Reminder
> These communities strictly forbid discussing illegal activities. Only discuss hacking in legal contexts (CTFs, your own lab, authorized bug bounties). Violating this will get you banned instantly and could have legal consequences.
