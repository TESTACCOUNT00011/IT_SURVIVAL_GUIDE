# Anki Flashcard Exports

This folder contains ready-to-import CSV files for Anki or any spaced repetition system (SRS). These flashcards cover key concepts from each section of the guide.

## How to Use These Files

1. **Download Anki**: Get it free at [apps.ankiweb.net](https://apps.ankiweb.net)
2. **Import CSV**: 
   - Open Anki
   - Click "File" -> "Import"
   - Select the CSV file you want
   - Choose or create a deck name
   - Map fields: Field 1 = Front, Field 2 = Back
3. **Study Daily**: Aim for 10-20 new cards per day

## Create Your Own Cards

When you learn something new, immediately make a flashcard. Use this format:

**Front:** What is an IP address?
**Back:** A unique number assigned to every device on a network (e.g., 192.168.1.1)

**Front:** What does DNS stand for?
**Back:** Domain Name System - translates domain names to IP addresses

## Recommended Settings for Beginners

- New cards/day: 10
- Review cards/day: 100
- Easy interval: 4 days
- Graduating interval: 3 days
- Starting ease: 250%

> [!TIP] Consistency Over Quantity
> Studying 10 minutes every day is better than 2 hours once a week. Spaced repetition only works with consistency.
