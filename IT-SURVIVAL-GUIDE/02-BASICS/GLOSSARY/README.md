# 📘 IT Glossary for Beginners

Essential IT terms explained in simple language. Bookmark this and refer back often!

---

## A

**API (Application Programming Interface)**  
A set of rules that allows different software applications to communicate with each other. Like a waiter taking your order to the kitchen.

**Algorithm**  
A step-by-step procedure for solving a problem or completing a task. Like a recipe for cooking.

**Authentication**  
The process of verifying who someone is. Username + password is the most common form.

**Bandwidth**  
The maximum amount of data that can be transferred over a network connection in a given time. Think of it as the width of a highway—wider = more traffic.

**Binary**  
A number system using only two digits: 0 and 1. This is the fundamental language of computers.

**Bug**  
An error or flaw in software that causes it to behave unexpectedly.

**Byte**  
A unit of digital information, typically consisting of 8 bits. One byte can store one character of text.

---

## C

**Cache**  
Temporary storage that holds frequently accessed data for faster retrieval. Like keeping your favorite snacks within arm's reach.

**Cloud Computing**  
Delivering computing services (servers, storage, databases) over the internet instead of on physical machines you own.

**CLI (Command Line Interface)**  
A text-based interface for interacting with an operating system by typing commands. More powerful but less intuitive than clicking icons.

**CPU (Central Processing Unit)**  
The "brain" of the computer that executes instructions and processes data.

**Cybersecurity**  
The practice of protecting systems, networks, and programs from digital attacks.

---

## D

**Database**  
An organized collection of structured information stored electronically. Like a digital filing cabinet.

**Debugging**  
The process of finding and fixing bugs (errors) in code.

**DNS (Domain Name System)**  
Translates human-readable domain names (like google.com) into IP addresses that computers understand. Like a phonebook for the internet.

**Data Analysis**  
The process of examining, cleaning, and interpreting data to discover useful information and support decision-making.

---

## E

**Encryption**  
Converting data into a coded format to prevent unauthorized access. Only those with the decryption key can read it.

**Endpoint**  
Any device that connects to a network (computer, phone, tablet, IoT device).

---

## F

**Firewall**  
A security system that monitors and controls incoming and outgoing network traffic based on predetermined security rules. Like a bouncer for your network.

**FTP (File Transfer Protocol)**  
A standard network protocol used to transfer files between computers over a network.

---

## G

**Git**  
A version control system that tracks changes in source code during software development. Allows multiple people to work on the same project.

**GUI (Graphical User Interface)**  
A visual way to interact with devices using icons, menus, and pointers (what you see when you use Windows or macOS).

---

## H

**Hardware**  
Physical components of a computer system (monitor, keyboard, CPU, etc.) that you can touch.

**HTTP/HTTPS**  
HyperText Transfer Protocol (Secure) - The foundation of data communication on the web. HTTPS adds encryption for security.

**HTML**  
HyperText Markup Language - The standard language for creating web pages.

---

## I

**IP Address**  
A unique numerical label assigned to each device on a network (e.g., 192.168.1.1). Like your home address but for devices.

**ISP (Internet Service Provider)**  
A company that provides internet access to customers (Comcast, AT&T, Verizon, etc.).

**IDE (Integrated Development Environment)**  
Software application that provides comprehensive facilities for programmers to write and test code (VS Code, PyCharm, etc.).

---

## J

**JavaScript**  
A programming language used primarily for creating interactive effects within web browsers.

**JSON**  
JavaScript Object Notation - A lightweight data format used for storing and exchanging data.

---

## K

**Kernel**  
The core part of an operating system that manages system resources and communication between hardware and software.

**Kbps/Mbps/Gbps**  
Kilobits/Megabits/Gigabits per second - Units of data transfer speed. Higher = faster.

---

## L

**LAN (Local Area Network)**  
A network that connects computers within a limited area like a home, office, or building.

**Linux**  
An open-source operating system based on Unix. Widely used in servers, cloud computing, and development.

**Latency**  
The delay before a data transfer begins following an instruction. Lower latency = more responsive connection.

---

## M

**Malware**  
Malicious software designed to harm or exploit computers (viruses, ransomware, spyware, etc.).

**Motherboard**  
The main circuit board of a computer that connects all components together.

**MAC Address**  
A unique identifier assigned to a network interface card (NIC) for communications on a network.

---

## N

**Network**  
Two or more computers connected together to share resources and information.

**NIC (Network Interface Card)**  
Hardware component that allows a computer to connect to a network.

**Node**  
Any device connected to a network (computer, printer, router, etc.).

---

## O

**Open Source**  
Software with source code that anyone can inspect, modify, and enhance. Free to use and modify.

**OS (Operating System)**  
System software that manages computer hardware and software resources (Windows, macOS, Linux, etc.).

**Object-Oriented Programming (OOP)**  
A programming paradigm based on objects containing data and code, rather than functions and logic.

---

## P

**Packet**  
A small unit of data transmitted over a network. Large files are broken into packets for transmission.

**Phishing**  
A cyberattack method using fraudulent emails or messages to trick people into revealing sensitive information.

**Port**  
A virtual endpoint for network communications. Different services use different ports (HTTP uses port 80, HTTPS uses 443).

**Protocol**  
A set of rules governing data exchange between devices (TCP/IP, HTTP, FTP, etc.).

**Python**  
A high-level, beginner-friendly programming language widely used in web development, data analysis, and automation.

---

## R

**RAM (Random Access Memory)**  
Temporary memory that stores data the CPU is actively using. Faster than storage but loses data when powered off.

**Router**  
A networking device that forwards data packets between computer networks. Directs traffic on your network.

**Remote Work**  
Working from a location outside the traditional office, often from home, using technology to stay connected.

---

## S

**Server**  
A computer or system that provides resources, data, or services to other computers (clients) over a network.

**SSD (Solid State Drive)**  
A fast storage device with no moving parts. Much faster than traditional hard drives.

**SQL**  
Structured Query Language - Used to manage and query relational databases.

**Subnet**  
A logical subdivision of an IP network. Used to organize and secure networks.

**SaaS/PaaS/IaaS**  
Cloud service models: Software/Platform/Infrastructure as a Service.

---

## T

**TCP/IP**  
Transmission Control Protocol/Internet Protocol - The fundamental communication protocols of the internet.

**Terminal/Console**  
A program that provides a command-line interface to interact with the operating system.

**Trojan**  
A type of malware disguised as legitimate software. Named after the Trojan Horse from Greek mythology.

**Two-Factor Authentication (2FA)**  
A security process requiring two forms of identification to access an account (password + phone code, for example).

---

## U

**URL**  
Uniform Resource Locator - The address of a resource on the internet (what you type into a browser).

**USB**  
Universal Serial Bus - A standard for cables and connectors that link computers to peripheral devices.

**UI/UX**  
User Interface / User Experience - Design aspects of software focusing on usability and user satisfaction.

---

## V

**Virtualization**  
Creating virtual versions of hardware, operating systems, or networks. Allows running multiple systems on one physical machine.

**Virus**  
A type of malware that replicates itself by modifying other programs and inserting its own code.

**VPN (Virtual Private Network)**  
A service that creates a secure, encrypted connection over the internet, protecting privacy and bypassing restrictions.

---

## W

**Web Browser**  
Software application used to access and view websites (Chrome, Firefox, Safari, Edge).

**Wi-Fi**  
Wireless networking technology that allows devices to connect to a network without cables.

**Worm**  
A type of malware that replicates itself to spread to other computers, often without user interaction.

---

## Quick Reference Tables

### Common Ports
| Port | Service |
|------|---------|
| 21 | FTP |
| 22 | SSH |
| 80 | HTTP |
| 443 | HTTPS |
| 3389 | Remote Desktop |

### Data Size Units
| Unit | Size | Example |
|------|------|---------|
| Byte | 1 character | The letter "A" |
| KB | 1,024 bytes | A short email |
| MB | 1,024 KB | A photo |
| GB | 1,024 MB | A movie |
| TB | 1,024 GB | Entire TV series |

### Number Systems
| System | Digits Used | Used By |
|--------|-------------|---------|
| Binary | 0, 1 | Computers |
| Decimal | 0-9 | Humans |
| Hexadecimal | 0-9, A-F | Programmers |
