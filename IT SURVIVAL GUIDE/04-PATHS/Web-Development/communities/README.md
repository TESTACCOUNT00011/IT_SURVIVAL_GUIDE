# Web Development Communities

Join these groups to ask questions, find mentors, and stay updated.

## Top Tier Communities

- **The Odin Project Discord**
  - Active community of learners.
  - Channels for HTML, CSS, JS, Ruby, Node.
  - Helpful moderators.

- **r/webdev (Reddit)**
  - News, tutorials, and career advice.
  - Search before posting.

- **Dev.to**
  - Blogging platform for developers.
  - Write articles to solidify learning.
  - Supportive comment sections.

## Specialized Chats

- **Reactiflux**: For React developers (Discord).
- **Vue Land**: For Vue.js developers (Discord).
- **CSS-Tricks**: For design and layout questions.

## Practice Platforms

- **CodePen**: Share small snippets and demos.
- **Frontend Mentor**: Real-world design challenges.
- **Codewars**: Coding kata for logic practice.

## How to Get Value

1. **Lurk First**: Read the rules and observe conversations.
2. **Search Before Asking**: Your question was likely answered already.
3. **Show Effort**: When asking, share what you tried and the error message.
4. **Give Back**: As you learn, help newer beginners.

> [!WARNING] Scams
> Never pay someone who DMs you offering a "job" or "mentorship". Real mentors do not cold DM strangers asking for money.
