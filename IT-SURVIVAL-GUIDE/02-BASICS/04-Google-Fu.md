# Google Fu (Search Skills)

Knowing how to search is the most important skill in IT. You will spend more time searching than coding.

## Basic Operators

- **Exact Match**: `"error message"` searches for that exact phrase.
- **Exclude Words**: `python tutorial -video` removes video results.
- **Site Search**: `site:reddit.com best laptop` searches only Reddit.
- **File Type**: `filetype:pdf networking guide` finds PDFs.

## How to Ask

1. **Copy the Error**: Paste the exact error message in quotes.
2. **Add Context**: Add your OS or language. Example: `"Connection Refused" python windows`.
3. **Check Dates**: Tech changes fast. Filter results to "Past Year" if possible.

## Reading Results

- **StackOverflow**: Look for green checkmarks (accepted answers) and upvotes.
- **Official Docs**: Prioritize links from `mozilla.org`, `microsoft.com`, `python.org`.
- **Blogs**: Good for tutorials, but verify the date. Old tutorials may be broken.

> [!TIP] The 15-Minute Rule
> Try to solve it yourself for 15 minutes. If stuck, search. If still stuck after 30 minutes of searching, ask for help.
