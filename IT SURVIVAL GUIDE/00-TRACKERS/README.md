# 🗺️ Trackers & Checklists: Measure Your Progress

Learning tech is a marathon, not a sprint. Use these templates to track your progress, stay motivated, and prove your skills to employers.

---

## ✅ Basics Completion Checklist

Copy this and check off as you go!

### Phase 1: Computer Literacy
- [ ] I can install/uninstall programs safely
- [ ] I understand files, folders, and extensions
- [ ] I can use keyboard shortcuts (Ctrl+C, Ctrl+V, Alt+Tab)
- [ ] I have installed an adblocker (uBlock Origin)
- [ ] I use a password manager
- [ ] I can troubleshoot basic internet issues

### Phase 2: Typing & Efficiency
- [ ] My typing speed is 30+ WPM
- [ ] My typing speed is 50+ WPM
- [ ] I touch-type without looking at the keyboard
- [ ] I practice typing 10 mins/day

### Phase 3: Core Skills
- [ ] I can Google effectively (using quotes, site:, filetype:)
- [ ] I understand how the internet works (DNS, HTTP, IP)
- [ ] I can use the Command Line/Terminal basics
- [ ] I know what Git is and made my first commit
- [ ] I built a simple "Hello World" program

## 📝 Progress Log Template (For Interviews)

Keep a log of what you build. You'll use this for resumes and interviews.

```markdown
## Project: [Name]
- **Date:** [Month Year]
- **Tech Used:** [HTML, CSS, JS, Python, etc.]
- **Problem Solved:** [What does it do?]
- **Challenges Faced:** [What was hard?]
- **How I Fixed It:** [What did you learn?]
- **Link:** [GitHub/Live Demo]

## Concept Learned: [Topic]
- **Date:** [Date]
- **Source:** [Course/Video/Article]
- **Summary:** [Explain in 2 sentences]
- **Application:** [How will I use this?]
```

**Example:**
```markdown
## Project: Personal Portfolio
- **Date:** March 2024
- **Tech Used:** HTML, CSS, GitHub Pages
- **Problem Solved:** Needed a place to showcase my projects
- **Challenges Faced:** CSS Flexbox was confusing
- **How I Fixed It:** Watched Kevin Powell's tutorial and practiced for 2 hours
- **Link:** github.com/username/portfolio

## Concept Learned: APIs
- **Date:** April 5, 2024
- **Source:** freeCodeCamp YouTube
- **Summary:** APIs let apps talk to each other and fetch data
- **Application:** I'll use this to get weather data in my next project
```
