# Cloud Computing Ebooks

## Free & Legal (Community Regarded, Updated)

1. **AWS Well-Architected Framework**
   - Status: Free PDF (aws.amazon.com)
   - Level: Intermediate
   - Note: Essential reading for designing systems on AWS.

2. **Azure Architecture Center**
   - Status: Free online (docs.microsoft.com)
   - Level: All levels
   - Note: Microsoft's official best practices.

3. **Google Cloud Architecture Framework**
   - Status: Free online (cloud.google.com)
   - Level: Intermediate
   - Note: GCP design principles.

4. **Terraform Documentation & Tutorials**
   - Status: Free online (developer.hashicorp.com)
   - Level: Beginner to Advanced
   - Note: Best IaC learning resource.

5. **Kubernetes Documentation**
   - Status: Free online (kubernetes.io)
   - Level: Intermediate to Advanced
   - Note: Official docs with interactive tutorials.

> [!TIP] Hands-On First
> Cloud cannot be learned by reading alone. You must build. Use the free tiers of AWS/Azure/GCP. Set a budget alert for $5 to avoid surprise charges. Books should supplement labs, not replace them.
