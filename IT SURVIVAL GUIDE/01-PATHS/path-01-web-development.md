# Path 1: Web Development

## What You Will Do
Build websites and web applications. Everything from simple landing pages to complex platforms like Facebook or Airbnb.

## Day 1 Challenge
Create a simple HTML file with a heading and a paragraph. Open it in your browser. If you see your text, you have started.

## Learning Roadmap

### Phase 1: The Basics (Weeks 1-4)
- **HTML**: Structure of web pages.
- **CSS**: Styling and layout.
- **JavaScript**: Interactivity.
- **Resource**: [[The Odin Project]](https://www.theodinproject.com) (Free).

### Phase 2: Advanced Frontend (Months 2-4)
- **Frameworks**: React, Vue, or Angular.
- **Responsive Design**: Making sites work on mobile.
- **Git/GitHub**: Version control.

### Phase 3: Backend (Months 5-8)
- **Server-side Language**: Node.js, Python, or Go.
- **Databases**: SQL (PostgreSQL) and NoSQL (MongoDB).
- **APIs**: How frontend talks to backend.

### Phase 4: Deployment & DevOps (Month 9+)
- **Hosting**: Vercel, Netlify, AWS.
- **CI/CD**: Automated testing and deployment.

## Domain Goodies

- **JavaScript.info**: Deep dive into JS (Free).
