## Available Paths

### 1. Web Development
Build websites and web applications.
- **Focus**: HTML, CSS, JavaScript, Frameworks (React, Vue), Backend (Node, Python).
- **Best for**: Creators who like visual results.
- **File**: [[01-PATHS/path-01-web-development]]

### 2. IT Support & SysAdmin
Keep systems running, fix hardware/software issues, manage networks.
- **Focus**: Troubleshooting, Windows/Linux Admin, Networking, Active Directory.
- **Best for**: Problem solvers who like helping people.
- **File**: [[01-PATHS/path-02-it-support]]

### 3. Data Analysis
Interpret data to help businesses make decisions.
- **Focus**: Excel, SQL, Python/R, Visualization (Tableau, PowerBI).
- **Best for**: Detectives who love patterns and statistics.
- **File**: [[01-PATHS/path-03-data-analysis]]

### 4. Cybersecurity
Protect systems from attacks and investigate breaches.
- **Focus**: Network Security, Ethical Hacking, Compliance, Forensics.
- **Best for**: Guardians who think like attackers.
- **File**: [[01-PATHS/path-04-cybersecurity]]

### 5. Cloud Computing
Design and manage infrastructure on AWS, Azure, or Google Cloud.
- **Focus**: Virtualization, Containers (Docker/K8s), Infrastructure as Code.
- **Best for**: Architects who like scalable systems.
- **File**: [[01-PATHS/path-05-cloud-computing]]
