# Choose Your Path Quiz

Not sure which IT career fits you best? Answer these questions honestly—there are no wrong answers.

## How to Use This Quiz

1. Read each question carefully
2. Write down your answer (A, B, C, D, or E)
3. Count which letter you chose most often
4. Read the corresponding path recommendation

---

## The Questions

### 1. When you use a website, what interests you most?
- **A**: Making sure it loads fast and doesn't crash
- **B**: How it looks and feels—colors, layout, animations
- **C**: Whether my data is safe and private
- **D**: What patterns they see in user behavior
- **E**: Where it's hosted and how it scales globally

### 2. You're given a broken device. What's your first instinct?
- **A**: Google the error message and follow troubleshooting steps
- **B**: Ignore it, you want to build something new instead
- **C**: Check if it's been hacked or has security vulnerabilities
- **D**: Collect data on when/how it breaks to find patterns
- **E**: Research if moving it to the cloud would solve the problem

### 3. Which type of project sounds most fun?
- **A**: Setting up a home network and getting everything connected
- **B**: Building a personal website from scratch
- **C**: Learning how to hack (ethically) and protect systems
- **D**: Analyzing Spotify data to find your listening patterns
- **E**: Deploying an app that automatically scales with users

### 4. What's your preferred way to learn?
- **A**: Hands-on labs with clear step-by-step instructions
- **B**: Building visual things you can show others immediately
- **C**: Solving puzzles and Capture-The-Flag challenges
- **D**: Working with real datasets and finding insights
- **E**: Understanding architecture diagrams and system design

### 5. Which task would you rather do for 8 hours?
- **A**: Troubleshoot why 10 different people can't print
- **B**: Perfect the CSS animation on a button
- **C**: Audit a system for security vulnerabilities
- **D**: Clean messy data and create visualizations
- **E**: Configure auto-scaling rules for a cloud service

### 6. What frustrates you the most?
- **A**: When technology just won't work and you don't know why
- **B**: Ugly interfaces that are hard to use
- **C**: People using "password123" as their password
- **D**: Bad data quality ruining your analysis
- **E**: Servers crashing during high traffic

### 7. Which job description excites you?
- **A**: "Ensure all employee systems run smoothly and resolve technical issues"
- **B**: "Create beautiful, responsive websites that delight users"
- **C**: "Protect organization from cyber threats and conduct penetration testing"
- **D**: "Turn raw data into actionable business insights"
- **E**: "Design and maintain cloud infrastructure for global applications"

### 8. What's your math comfort level?
- **A**: Basic arithmetic is fine, nothing too complex
- **B**: I can handle logic, but I'm not a mathematician
- **C**: Logic puzzles yes, calculus no
- **D**: I'm comfortable with statistics and formulas
- **E**: I understand logic but prefer architecture over calculations

### 9. How do you handle stress?
- **A**: Calmly follow procedures and documentation
- **B**: Get in the zone and lose track of time building
- **C**: Thrive under pressure during incident response
- **D**: Methodically work through problems step-by-step
- **E**: Think systematically about root causes

### 10. What's your end goal?
- **A**: Become a Systems Administrator or Network Engineer
- **B**: Become a Frontend/Full-Stack Developer
- **C**: Become a Security Analyst or Ethical Hacker
- **D**: Become a Data Analyst or Data Scientist
- **E**: Become a Cloud Architect or DevOps Engineer

## Results

### Mostly A's: IT Support & System Administration
**You're the backbone of tech.** You enjoy solving tangible problems, helping people, and ensuring systems run smoothly. You're patient, methodical, and good under pressure.

**Next Steps:**
- Start with the [[../04-PATHS/01-IT-Support/Roadmap|IT Support Roadmap]]
- Get CompTIA A+ certification
- Set up a home lab to practice

### Mostly B's: Web Development
**You're a creator.** You love building things people can see and interact with. You have an eye for design and enjoy immediate visual feedback from your work.

**Next Steps:**
- Start with the [[../04-PATHS/02-Web-Development/Roadmap|Web Development Roadmap]]
- Build your portfolio website first
- Join coding communities for support

### Mostly C's: Cybersecurity
**You're a protector.** You think like both a defender and an attacker. You enjoy puzzles, continuous learning, and the thrill of staying ahead of threats.

**Next Steps:**
- Start with the [[../04-PATHS/03-Cybersecurity/Roadmap|Cybersecurity Roadmap]]
- Try HackTheBox or TryHackMe platforms
- Learn networking fundamentals first

### Mostly D's: Data Analysis
**You're a detective.** You love finding stories hidden in numbers. You're curious, analytical, and enjoy turning chaos into clarity.

**Next Steps:**
- Start with the [[../04-PATHS/04-Data-Analysis/Roadmap|Data Analysis Roadmap]]
- Learn SQL and Python
- Practice with real datasets on Kaggle

### Mostly E's: Cloud Computing
**You're an architect.** You think in systems and scale. You enjoy designing solutions that work for millions of users and optimizing efficiency.

**Next Steps:**
- Start with the [[../04-PATHS/05-Cloud-Computing/Roadmap|Cloud Computing Roadmap]]
- Get AWS Cloud Practitioner or Azure Fundamentals cert
- Learn Linux and networking basics

### Mixed Results?
That's normal! Many paths overlap:
- **A + E**: Consider DevOps or Site Reliability Engineering
- **B + E**: Look into Full-Stack Development with cloud deployment
- **C + A**: Security Operations Center (SOC) roles
- **D + E**: Cloud Data Engineering

**Remember:** Your first choice isn't permanent. Many professionals switch paths after 2-3 years. Start somewhere and adjust based on what you enjoy day-to-day.
