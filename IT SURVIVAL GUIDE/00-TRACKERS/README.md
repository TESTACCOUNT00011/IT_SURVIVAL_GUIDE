# Progress Trackers

Tracking your learning is crucial for staying motivated and identifying gaps in your knowledge.

-

- [ ] Can type without looking at keyboard (30+ WPM)

- [ ] Understand files, folders, and extensions
- [ ] Can search effectively using Google operators
- [ ] Know how to install/uninstall software safely

### Core Concepts (Week 3-6)
- [ ] Understand how the internet works (DNS, HTTP, IP)
- [ ] Can use command line for basic navigation
- [ ] Understand variables, loops, and functions
- [ ] Created a GitHub account and pushed code
- [ ] Understand basic hardware components

## 30-Day Challenge Calendar

Create a grid for 30 days. Mark each day you study for at least 30 minutes.

```
Day 1-10:  [ ][ ][ ][ ][ ][ ][ ][ ][ ][ ]
Day 11-20: [ ][ ][ ][ ][ ][ ][ ][ ][ ][ ]
Day 21-30: [ ][ ][ ][ ][ ][ ][ ][ ][ ][ ]
```

**Goal**: Fill every box. If you miss a day, never miss two in a row.

## Reflection Prompts

Use these questions weekly:

1.  What was the biggest breakthrough this week?
2.  What concept am I still struggling with?
3.  Did I help anyone else learn something?
4.  What will I focus on next week?
5.  Am I spending too much time on tutorials vs. building?

> [!WARNING]
> Don't track metrics that don't matter. Lines of code written, hours watched, or courses completed mean nothing if you can't apply the knowledge. Track **projects built** and **problems solved**.
