# ✅ Day 1 Starter Checklist

Welcome to your IT journey! This checklist guides you through your **first day** step-by-step. Don't worry about being perfect—just get started!

---

## 🌅 Morning: Setup & Mindset (30-60 minutes)

### ☐ 1. Welcome & Mindset Check
- [ ] Take a deep breath—you've got this!
- [ ] Write down **why** you're starting this journey in your [[Daily-Log]]
- [ ] Remember: Every expert was once a beginner
- [ ] Commit to consistency over perfection

### ☐ 2. Verify Your Setup
- [ ] Computer is working (any modern laptop/desktop is fine)
- [ ] Internet connection is stable
- [ ] Obsidian is installed and working
- [ ] You're in the right folder: `IT-SURVIVAL-GUIDE/01-START-HERE`

### ☐ 3. Create Your First Daily Log
- [ ] Copy the [[../00-TEMPLATES/Daily-Log|Daily Log Template]]
- [ ] Name it with today's date: `YYYY-MM-DD.md`
- [ ] Fill in the "Today's Goal" section
- [ ] Example goal: "Complete Day 1 orientation and explore career paths"

---

## 📚 Midday: Learning & Exploration (60-90 minutes)

### ☐ 4. Read the Welcome Guide
- [ ] Open [[Welcome|Welcome to IT Survival Guide]]
- [ ] Read the entire introduction
- [ ] Click through at least 3 links to see how navigation works
- [ ] Bookmark this page for future reference

### ☐ 5. Understand Your Options
- [ ] Open [[../04-PATHS/Path-Comparison|Career Path Comparison]]
- [ ] Read about all 5 career paths
- [ ] Don't decide yet—just explore!
- [ ] Jot down initial thoughts in your Daily Log:
  - Which path sounds most interesting?
  - Which seems most intimidating?
  - What questions do you have?

### ☐ 6. Learn Basic Terminology
- [ ] Open [[../02-BASICS/GLOSSARY/README|IT Glossary]]
- [ ] Read terms A through M (or pick 10 random terms)
- [ ] Create flashcards for 5 terms you didn't know
- [ ] Add them to your notes or [[../98-ANKI/decks/General-IT-Terms|Anki deck]]

---

## 🎯 Afternoon: First Actions (60 minutes)

### ☐ 7. Choose Your Starting Point
**Option A: Complete Beginner**
- [ ] Start with [[../02-BASICS/Computer-Basics|Computer Basics]]
- [ ] Complete the first module
- [ ] Take notes using [[../00-TEMPLATES/Learning-Summary|Learning Summary Template]]

**Option B: Some Tech Experience**
- [ ] Review [[../04-PATHS/Path-Comparison|Career Paths]] again
- [ ] Pick one path to explore first
- [ ] Open that path's Roadmap
- [ ] Read the "Month 1" section

**Option C: Ready to Dive In**
- [ ] Choose your career path
- [ ] Open the Roadmap
- [ ] Start Day 1 tasks from the roadmap
- [ ] Set up your [[../00-TEMPLATES/Project-Tracker|Project Tracker]]

### ☐ 8. Set Up Your Learning Environment
- [ ] Install essential software from [[../02-BASICS/Essential-Software|Essential Software Guide]]
- [ ] At minimum:
  - [ ] Web browser (Chrome or Firefox)
  - [ ] Text editor or IDE (VS Code recommended)
  - [ ] Note-taking system (you're using Obsidian!)
- [ ] Organize your desktop/workspace
- [ ] Remove distractions during study time

### ☐ 9. Join the Community
- [ ] Visit [[../99-RESOURCES/README|Resources Hub]]
- [ ] Find communities for your chosen path
- [ ] Join at least ONE of these:
  - [ ] Reddit community (r/learnprogramming, r/ITCareerQuestions, etc.)
  - [ ] Discord server
  - [ ] Local meetup group
  - [ ] Study group
- [ ] Introduce yourself (template below 👇)

---

## 🌙 Evening: Reflection & Planning (20-30 minutes)

### ☐ 10. Reflect on Day 1
In your Daily Log, answer:
- [ ] What did I learn today?
- [ ] What was surprising or interesting?
- [ ] What felt overwhelming or confusing?
- [ ] What am I excited about?

### ☐ 11. Plan Day 2
- [ ] Set a specific time to study tomorrow
- [ ] Choose ONE specific task for tomorrow
- [ ] Example: "Complete Computer Basics Module 2" or "Read Web Dev Roadmap Week 1"
- [ ] Prepare your workspace tonight (close unnecessary tabs, etc.)

### ☐ 12. Celebrate!
- [ ] Acknowledge you completed Day 1! 🎉
- [ ] Share your progress (optional):
  - Post in community forums
  - Tell a friend/family member
  - Tweet about your journey
- [ ] Do something relaxing—you earned it!

## 📝 Introduction Template for Communities

Copy and customize this when joining communities:

```
Hi everyone! 👋

I'm [Your Name] and I'm just starting my IT journey. 

Background: [Your current situation - e.g., "working in retail," "recent grad," "career changer"]
Goal: [What you hope to achieve - e.g., "land first tech job," "learn web development"]
Current Focus: [What you're studying now - e.g., "computer basics," "choosing a path"]

Excited to learn from all of you! Any advice for a complete beginner?

#Newbie #ITJourney
```

## 🆘 Feeling Overwhelmed?

**Normal!** Here's what to do:

1. **Stop and breathe** - You don't need to do everything today
2. **Pick ONE thing** from this checklist and complete just that
3. **Remember**: This is a marathon, not a sprint
4. **Come back tomorrow** - Consistency beats intensity

### Minimum Viable Day 1
If you're short on time, do ONLY these three things:
1. ☐ Read the [[Welcome|Welcome Guide]]
2. ☐ Write today's goal in a Daily Log
3. ☐ Plan ONE thing to do tomorrow

That's it! You've started. Tomorrow, do a bit more.

## 📈 What Success Looks Like

**Day 1 Success Criteria:**
- ✅ You opened Obsidian and navigated the guide
- ✅ You learned at least ONE new thing
- ✅ You wrote down your thoughts somewhere
- ✅ You planned to come back tomorrow

**NOT Required:**
- ❌ Understanding everything perfectly
- ❌ Choosing your career path definitively
- ❌ Installing all the software
- ❌ Studying for hours
