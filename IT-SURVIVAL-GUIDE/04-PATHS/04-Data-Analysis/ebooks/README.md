# Data Analysis Ebooks

## Free & Legal (Community Regarded)

- **Python for Everybody** by Charles Severance
  - Free online and PDF.
  - Gentle intro to Python for non-programmers.
  - Covers data structures and basic analysis.

- **Think Stats** by Allen Downey
  - Free PDF.
  - Probability and statistics for programmers.
  - Uses Python examples.

- **Kaggle Micro-Courses**
  - Not books, but interactive notebooks.
  - Cover Pandas, ML, SQL, Visualization.
