# IT Support Path

Help people solve technical problems. Manage systems, networks, and hardware.

## What You Will Do

- Troubleshoot hardware and software issues.
- Set up user accounts and permissions.
- Maintain servers and networks.
- Provide customer service for tech problems.

## Roadmap

### Phase 1: The Basics (Months 1-3)
- **Hardware**: CPU, RAM, Storage, Peripherals.
- **OS Installation**: Windows, Linux, macOS setup.
- **Networking Basics**: IP addresses, DNS, DHCP.
- **Troubleshooting Methodology**: Isolate variables.

### Phase 2: Systems Administration (Months 4-6)
- **Active Directory**: User management.
- **Linux Command Line**: Bash scripting.
- **Virtualization**: VirtualBox, VMware.
- **Cloud Basics**: AWS/Azure fundamentals.

### Phase 3: Advanced Skills (Months 7-9)
- **Security**: Firewalls, Antivirus, Backups.
- **Scripting**: PowerShell, Python for automation.
- **Ticketing Systems**: Jira, ServiceNow.

## Domain Goodies

- **Professor Messer**: Free videos for CompTIA certs.
- **Cisco Packet Tracer**: Network simulation tool.
- **Linux Journey**: Interactive Linux learning.
- **TryHackMe**: Beginner security rooms.
