# Your First 30 Days Sprint Plan

The first month is critical. This plan prevents overwhelm by breaking learning into manageable weekly sprints.

**Choose your path first:** [[Path-Quiz|Take the Path Quiz]] or see [[../04-PATHS/Path-Comparison|Path Comparison]]

---

## Week 1: Setup & Foundations (Days 1-7)

### Goal: Get everything installed and understand the basics

**Daily Time Commitment:** 1-2 hours

### Day 1: Orientation
- [ ] Read [[../01-START-HERE/00-Welcome|Welcome Guide]]
- [ ] Complete [[../01-START-HERE/Day-1-Checklist|Day 1 Checklist]]
- [ ] Set up your Obsidian vault for note-taking
- [ ] Join 1-2 communities from your path's community list

### Day 2: Computer Basics
- [ ] Read [[../02-BASICS/01-Computer-Basics|Computer Basics]]
- [ ] Learn file systems (Windows/Mac/Linux)
- [ ] Practice keyboard shortcuts
- [ ] Use [[../../00-TEMPLATES/Learning-Summary|Learning Summary Template]] to document what you learned

### Day 3: Typing Practice
- [ ] Read [[../02-BASICS/02-Typing|Typing Guide]]
- [ ] Sign up for typing club or keybr.com
- [ ] Practice 20 minutes (aim for 30+ WPM eventually)
- [ ] Log progress in [[../../00-TEMPLATES/Goal-Setter|Goal Setter Template]]

### Day 4: Security Setup
- [ ] Read [[../02-BASICS/03-Adblock-Security|Security Basics]]
- [ ] Install uBlock Origin
- [ ] Set up a password manager (Bitwarden recommended)
- [ ] Enable 2FA on important accounts

### Day 5: Google-Fu
- [ ] Read [[../02-BASICS/04-Google-Fu|Google Search Techniques]]
- [ ] Practice advanced search operators
- [ ] Learn to read error messages effectively
- [ ] Document common errors in [[../../00-TEMPLATES/Troubleshooting-Log|Troubleshooting Log]]

### Day 6: Path-Specific Setup
**IT Support:**
- [ ] Install VirtualBox
- [ ] Download a Linux ISO (Ubuntu)
- [ ] Create your first VM

**Web Development:**
- [ ] Install VS Code
- [ ] Install Node.js
- [ ] Create "Hello World" HTML file

**Cybersecurity:**
- [ ] Install Kali Linux in VM
- [ ] Set up TryHackMe account
- [ ] Complete "Pre-Security" learning path intro

**Data Analysis:**
- [ ] Install Python + Anaconda
- [ ] Install Jupyter Notebook
- [ ] Load your first dataset

**Cloud Computing:**
- [ ] Create AWS/Azure free account
- [ ] Complete cloud provider's "Getting Started" module
- [ ] Learn basic Linux commands

### Day 7: Review & Rest
- [ ] Review notes from the week using [[../../00-TEMPLATES/Learning-Summary|Learning Summary]]
- [ ] Write down 3 things you learned
- [ ] Write down 2 questions you still have
- [ ] REST—don't burn out!

## Week 2: Core Skills Building (Days 8-14)

### Goal: Start building foundational skills specific to your path

**Daily Time Commitment:** 2-3 hours

### Days 8-10: Fundamentals
Focus on the first phase of your path's roadmap:
- [ ] Follow [[../04-PATHS/01-IT-Support/Roadmap|IT Support: Phase 1]] OR
- [ ] Follow [[../04-PATHS/02-Web-Development/Roadmap|Web Dev: Phase 1]] OR
- [ ] Follow [[../04-PATHS/03-Cybersecurity/Roadmap|Security: Phase 1]] OR
- [ ] Follow [[../04-PATHS/04-Data-Analysis/Roadmap|Data: Phase 1]] OR
- [ ] Follow [[../04-PATHS/05-Cloud-Computing/Roadmap|Cloud: Phase 1]]

Use [[../../00-TEMPLATES/Study-Session|Study Session Template]] for each study block.

### Days 11-12: First Mini-Project
Build something tiny to apply what you learned:

**IT Support:** Document how to set up a printer on 3 different OSes
**Web Dev:** Build a single-page personal bio site
**Security:** Complete 3 TryHackMe rooms
**Data:** Analyze a simple CSV and create 3 charts
**Cloud:** Deploy a static website to S3/Azure Blob

Document it with [[../../00-TEMPLATES/Project-Tracker|Project Tracker]]

### Days 13-14: Review & Community
- [ ] Review all notes from Week 2
- [ ] Post one question in your chosen community
- [ ] Answer one question if you can (teaching reinforces learning)
- [ ] Update your goals in [[../../00-TEMPLATES/Goal-Setter|Goal Setter]]

## Week 3: First Real Project (Days 15-21)

### Goal: Complete one portfolio-worthy mini-project

**Daily Time Commitment:** 2-4 hours

### Days 15-18: Build Phase
Work on your first real project from your path's roadmap:

**IT Support:** Home lab network documentation
**Web Dev:** To-Do List App with local storage
**Security:** Write-up of a HackTheBox machine
**Data:** Exploratory data analysis on a Kaggle dataset
**Cloud:** Multi-tier architecture deployment

Use [[../../00-TEMPLATES/Project-Tracker|Project Tracker]] daily.

### Day 19: Documentation
- [ ] Write a README for your project
- [ ] Take screenshots
- [ ] Document challenges faced and solutions
- [ ] Use [[../../00-TEMPLATES/Portfolio-Showcase|Portfolio Showcase Template]]

### Days 20-21: Polish & Share
- [ ] Fix bugs/issues
- [ ] Share your project in a community
- [ ] Ask for feedback
- [ ] Celebrate completing your first project! 🎉

## Week 4: Review & Next Steps (Days 22-30)

### Goal: Solidify learning and plan the next month

**Daily Time Commitment:** 2-3 hours

### Days 22-24: Fill Knowledge Gaps
- [ ] Review concepts that felt shaky
- [ ] Re-read documentation on confusing topics
- [ ] Watch video tutorials on difficult concepts
- [ ] Use [[../../00-TEMPLATES/Troubleshooting-Log|Troubleshooting Log]] for recurring issues

### Days 25-26: Anki Flashcards
- [ ] Import flashcards for your path from [[../98-ANKI/decks|Anki Decks]]
- [ ] Do your first review session (20-30 cards)
- [ ] Add 5 custom cards for terms you struggled with
- [ ] Make Anki a daily habit (15 min/day)

### Days 27-28: Second Mini-Project
Start a second, slightly harder project:
- [ ] Choose from your path's project list
- [ ] Plan using [[../../00-TEMPLATES/Project-Tracker|Project Tracker]]
- [ ] Build for 2 days (don't aim for perfection)

### Day 29: Month 1 Reflection
Use [[../../00-TEMPLATES/Learning-Summary|Learning Summary]] to answer:
1. What did I enjoy most?
2. What frustrated me?
3. What surprised me about this field?
4. Do I want to continue this path? (It's okay to switch!)
5. What are my goals for Month 2?

### Day 30: Plan Month 2
- [ ] Review your path's full roadmap
- [ ] Set 3 specific goals for Month 2
- [ ] Schedule study time in your calendar
- [ ] Reward yourself for completing 30 days! 🏆

## After Day 30

You've completed your first sprint! Now:

1. **Continue with your path's full roadmap** in [[../04-PATHS|Career Paths]]
2. **Join the community** and start engaging regularly
3. **Build projects consistently** (aim for 1 project per month)
4. **Start thinking about certifications** (see path roadmaps)
5. **Consider finding a study buddy** or accountability partner

### Signs You Should Switch Paths:
- You dread opening your laptop to study
- The work feels boring, not challenging
- You're more interested in another path's projects
- After 60 days, you still don't understand the "why" behind the work

**Remember:** Switching paths isn't failure—it's optimization. Many successful techies tried 2-3 paths before finding their fit.

## Quick Reference: Daily Routine Example

**Morning (30 min):**
- Review Anki flashcards
- Check yesterday's notes

**Study Block (1-2 hours):**
- Work on current project or learning module
- Use Pomodoro technique (25 min work, 5 min break)
- Document in templates

**Evening (15 min):**
- Write 3 bullet points about what you learned
- Note any blockers for tomorrow
- Close laptop and rest!
