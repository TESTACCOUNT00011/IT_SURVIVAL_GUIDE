# Path 2: IT Support & System Administration

## What You Will Do
Help people solve technical problems. Set up computers, manage networks, and ensure business systems run smoothly. This is the most common entry point into tech.

## Day 1 Challenge
Open your computer's Task Manager (Windows) or Activity Monitor (Mac). Identify which program is using the most RAM. Google that program to learn what it does.

## Learning Roadmap

### Phase 1: Fundamentals (Weeks 1-4)
- **Hardware**: CPU, RAM, Storage, Peripherals.
- **OS Installation**: Windows, macOS, Linux basics.
- **Troubleshooting**: Systematic problem solving.
- **Resource**: Professor Messer CompTIA A+ videos (Free).

### Phase 2: Networking (Months 2-3)
- **IP Addresses, DNS, DHCP**: How devices talk.
- **Routers & Switches**: Basic configuration.
- **Wi-Fi Security**: WPA2/3, Enterprise setup.
- **Resource**: NetworkChuck YouTube channel.

### Phase 3: Server Management (Months 4-6)
- **Active Directory**: User management in companies.
- **Group Policy**: Controlling user settings.
- **Linux Command Line**: Basic server commands.
- **Resource**: TryHackMe "Pre-Security" path.

### Phase 4: Cloud Basics (Month 7+)
- **Azure AD / AWS IAM**: Cloud identity.
- **Virtual Machines**: Creating servers in the cloud.
- **Ticketing Systems**: Jira, ServiceNow.

## Domain Goodies
- **Professor Messer**: Free A+, Network+, Security+ training.
- **Cisco Packet Tracer**: Free network simulation software.
- **Linux Journey**: Interactive Linux learning.
- **TryHackMe**: Gamified security labs (free tier).

## Certifications to Target
- **CompTIA A+**: The gold standard for entry-level IT.
- **Google IT Support Professional Certificate**: Coursera (Financial aid available).
- **Microsoft MD-102**: Endpoint Administrator.
