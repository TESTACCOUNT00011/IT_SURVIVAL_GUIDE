# Computer Basics

## Understanding Your Environment

### The Desktop and Window Management
- **Desktop**: The main screen area where icons live.
- **Taskbar/Dock**: The bar at the bottom (Windows/Mac) showing open apps.
- **Minimize/Maximize/Close**: The three buttons on every window.

### Files and Folders
Think of your computer like a physical filing cabinet.
- **File**: A single document, picture, or program (e.g., `resume.pdf`, `photo.jpg`).
- **Folder**: A container to hold files (e.g., `Documents`, `Pictures`).
- **Path**: The address of a file (e.g., `C:\Users\Name\Documents\resume.pdf`).

> [!TIP] Organization Rule
> Never save files directly to the Desktop. Create folders inside `Documents` instead. A messy desktop slows you down mentally.

### Mouse and Keyboard Control
- **Left Click**: Select or open.
- **Right Click**: Show options menu (very important).
- **Double Click**: Open a file or folder.
- **Drag and Drop**: Move files by holding left click and dragging.
