# Free Courses & Certification Guides

This section contains legitimate, free resources to learn IT concepts and prepare for certifications without paying for expensive bootcamps.

## Legendary Free Courses (Hall of Fame)

These courses are universally respected in the industry. Completing them carries weight on a resume.

### Harvard CS50x: Introduction to Computer Science
- **Provider**: Harvard University (edX)
- **Cost**: Free (Certificate costs money, but knowledge is free)
- **Content**: C, Python, SQL, JavaScript, CSS, HTML, Data Structures, Algorithms.
- **Why it matters**: It is the gold standard for CS fundamentals. Hard but worth it.
- **Link**: cs50.harvard.edu/x

### Nand2Tetris: Build a Modern Computer from First Principles
- **Provider**: Coursera / nand2tetris.org
- **Cost**: Free
- **Content**: Build a computer from logic gates up to a Tetris game.
- **Why it matters**: You will understand exactly how hardware and software interact.
- **Link**: nand2tetris.org

### MIT Missing Semester
- **Provider**: MIT
- **Cost**: Free
- **Content**: Command line, Git, Vim, Debugging, Metaprogramming.
- **Why it matters**: Teaches the practical skills universities often skip.
- **Link**: missing.csail.mit.edu

## Certification Prep (Legal & Free)

Avoid "Brain Dumps" (stolen exam questions). They are illegal, often wrong, and can get you banned. Use these official or ethical resources instead.

### CompTIA Security+
- **Video Course**: Professor Messer (YouTube) - Complete free video series covering all objectives.
- **Practice Questions**: ExamCompass (Free quizzes).
- **Official Objectives**: Download from CompTIA website to know exactly what to study.

### AWS Cloud Practitioner (CLF-C01/C02)
- **Official Training**: AWS Skill Builder (Free digital training course).
- **Whitepapers**: AWS offers free "Well-Architected Framework" whitepapers.
- **Practice**: AWS provides free tier access to build hands-on projects.

### Linux Essentials / LPIC-1
- **Study Guide**: Linux Journey (linuxjourney.com) - Interactive free guide.
- **Practice**: OverTheWire Bandit (Game-based learning).

## Playgrounds (Safe Places to Break Things)

Do not practice on your main computer. Use these safe environments.

- **OverTheWire Bandit**: Learn Linux security by hacking through levels.
- **CodePen / JSFiddle**: Test HTML/CSS/JS safely in the browser.
- **Replit**: Run code in 50+ languages in the cloud.
- **Google Chrome Experiments**: See what is possible with web tech.

> [!WARNING] Avoid Brain Dumps
> Websites selling "real exam questions" are selling stolen property. Using them violates NDAs, can get your certification revoked permanently, and often teaches incorrect answers. Stick to official practice exams and study guides.
