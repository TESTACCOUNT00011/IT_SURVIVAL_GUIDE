# Web Development Ebooks

## Free & Legal (Community Regarded)

These books are free, legal, and regularly updated by their authors.

- **Eloquent JavaScript** by Marijn Haverbeke
  - Available online for free.
  - Covers JS from basics to advanced topics.
  - Includes exercises.

- **You Don't Know JS Yet** by Kyle Simpson
  - Deep dive into JavaScript mechanics.
  - Free on GitHub.
  - Essential for serious JS developers.

- **Roadmap.sh Guides**
  - Not a book, but structured reading lists.
  - Covers Frontend, Backend, and DevOps paths.
