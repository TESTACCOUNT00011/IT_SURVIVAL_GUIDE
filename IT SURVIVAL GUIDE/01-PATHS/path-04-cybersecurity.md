# 🔒 Path 4: Cybersecurity

**Protect systems, networks, and data from cyber attacks.**

---

## 🎯 What Do Cybersecurity Professionals Do?

Cybersecurity experts defend organizations by:
- Monitoring for security breaches
- Investigating incidents and attacks
- Implementing security measures
- Testing systems for vulnerabilities
- Developing security policies
- Training employees on security awareness
- Responding to and recovering from attacks

**You're a digital guardian protecting against hackers and criminals!**

---

## 🔧 Key Areas

### 1. Security Analyst / SOC Analyst
**Monitoring and responding to threats**

- Security Operations Center (SOC) work
- Monitoring security tools and alerts
- Incident response
- Threat analysis
- Log analysis

**You'll enjoy this if:** You like investigation and fast-paced environments

---

### 2. Penetration Tester / Ethical Hacker
**Finding vulnerabilities before bad guys do**

- Authorized hacking of systems
- Vulnerability assessments
- Security testing
- Writing reports with recommendations
- Staying updated on latest attack techniques

**You'll enjoy this if:** You think like an attacker and love puzzles

---

### 3. Security Engineer
**Building and maintaining security systems**

- Firewall configuration
- Security tool implementation
- Network security architecture
- Identity and access management
- Security automation

**You'll enjoy this if:** You like building and configuring systems

---

### 4. Incident Responder
**Handling security breaches**

- Investigating security incidents
- Containing and eradicating threats
- Forensic analysis
- Recovery planning
- Post-incident reporting

**You'll enjoy this if:** You stay calm under pressure and like detective work

---

### 5. Governance, Risk & Compliance (GRC)
**Policy and compliance focus**

- Security policy development
- Risk assessments
- Compliance audits (HIPAA, PCI-DSS, GDPR)
- Security awareness training
- Vendor risk management

**You'll enjoy this if:** You like documentation, policy, and big-picture thinking

## 📚 Learning Roadmap

### Phase 1: Foundations (8-12 weeks)

**CRITICAL: Build strong IT fundamentals first**

1. **Networking Deep Dive**
   - OSI and TCP/IP models
   - IP addressing and subnetting
   - Common protocols (TCP, UDP, HTTP, DNS, DHCP, SSH, FTP)
   - Network devices (routers, switches, firewalls)
   - Network segmentation and VLANs

2. **Operating Systems**
   - Windows internals (registry, services, event logs)
   - Linux command line mastery
   - File systems and permissions
   - Process management
   - Active Directory basics

3. **Security Fundamentals**
   - CIA triad (Confidentiality, Integrity, Availability)
   - Authentication vs. Authorization
   - Encryption basics
   - Common attack types (malware, phishing, DDoS)
   - Defense in depth

✅ **Project:** Set up a secure home network and document it

---

### Phase 2: Core Security Skills (12-16 weeks)

1. **Security Tools**
   - Firewalls (pfSense, iptables)
   - Intrusion Detection/Prevention (Snort, Suricata)
   - SIEM basics (Splunk, ELK Stack)
   - Vulnerability scanners (Nessus, OpenVAS)
   - Wireshark (packet analysis)

2. **Scripting & Automation**
   - Python for security tasks
   - Bash scripting
   - PowerShell for Windows administration
   - Automating security checks

3. **Web Application Security**
   - OWASP Top 10 vulnerabilities
   - SQL injection
   - Cross-site scripting (XSS)
   - Authentication flaws
   - Secure coding principles

4. **System Hardening**
   - Securing Windows and Linux
   - Patch management
   - Configuration baselines
   - Removing unnecessary services
   - Logging and monitoring setup

✅ **Project:** Build a vulnerable lab and practice attacking/defending it

---

### Phase 3: Specialized Skills (16-20 weeks)

**Choose your specialization track:**

#### Track A: Defensive Security (Blue Team)

1. **SIEM & Log Analysis**
   - Splunk or ELK Stack
   - Creating detection rules
   - Correlation searches
   - Alert tuning

2. **Incident Response**
   - IR methodology
   - Evidence collection
   - Malware analysis basics
   - Containment strategies
   - Post-incident review

3. **Threat Intelligence**
   - Threat actor profiles
   - MITRE ATT&CK framework
   - IOC (Indicators of Compromise)
   - Threat feeds

#### Track B: Offensive Security (Red Team)

1. **Penetration Testing Methodology**
   - Reconnaissance (passive & active)
   - Scanning and enumeration
   - Exploitation
   - Post-exploitation
   - Reporting

2. **Tools Mastery**
   - Kali Linux
   - Metasploit
   - Burp Suite (web apps)
   - Nmap
   - Hashcat/John the Ripper (password cracking)

3. **Practice Platforms**
   - HackTheBox
   - TryHackMe
   - VulnHub
   - CTF competitions

#### Track C: General Security Engineering

1. **Cloud Security**
   - AWS/Azure/GCP security features
   - Identity and Access Management (IAM)
   - Security groups and NACLs
   - Cloud-native security tools

2. **Network Security Architecture**
   - Zero Trust model
   - Network segmentation
   - VPNs and remote access
   - Secure network design

✅ **Project:** Complete certification practical exam or major portfolio project

---

### Phase 4: Advanced Topics (Ongoing)

- Digital forensics
- Malware reverse engineering
- Advanced persistent threats (APTs)
- Security orchestration and automation (SOAR)
- Container and Kubernetes security
- DevSecOps practices
- Industrial control systems (ICS/SCADA) security

✅ **Project:** Contribute to open-source security tools or research

## ✅ How to Know You're Ready

You're ready for entry-level security roles when you can:

- Explain networking concepts confidently
- Understand common attacks and defenses
- Use basic security tools (Wireshark, Nmap, etc.)
- Read and analyze logs
- Write clear reports
- Show hands-on practice (labs, CTFs, certifications)
- Demonstrate passion through projects and continuous learning

## 💡 Tips for Breaking Into Cybersecurity

### 1. Build IT Foundations First
Most security professionals start in IT support or system administration. Don't skip this!

### 2. Get Security+ Certification
It's the baseline certification most HR departments look for.

### 3. Practice Hands-On
Theory isn't enough. Use TryHackMe, HackTheBox, and build a home lab.

### 4. Document Your Journey
Start a blog, GitHub, or Twitter. Show your learning and projects.

### 5. Network Extensively
Attend local meetups, BSides conferences, connect on LinkedIn.

### 6. Consider Starting in IT
SOC Analyst or IT roles can be stepping stones to security positions.

### 7. Specialize Eventually
Start broad, then dive deep into one area (pentesting, incident response, etc.)

### 8. Stay Current
Security changes daily. Follow news, blogs, and researchers.

## 💎 Domain Goodies: Legendary Resources for Cybersecurity

Break things (legally) and learn to protect them with these elite resources.

- **[Harvard CS50x](https://cs50.harvard.edu/x/)**: Understanding memory management and pointers (Week 4 & 5) is the foundation of understanding buffer overflows and many exploits.
- **[Nand2Tetris](https://www.nand2tetris.org/)**: Knowing how a computer is built from gates up helps you understand hardware-level attacks and side-channel vulnerabilities.
- **[OverTheWire (Bandit)](https://overthewire.org/wargames/bandit/)**: The ultimate "fuck around and find out" game for Linux security. Start at Level 0. It's addictive and teaches real SSH and command-line skills.
- **[TryHackMe](https://tryhackme.com/) & [HackTheBox](https://www.hackthebox.com/)**: Gamified hacking labs. TryHackMe is better for beginners; HTB is more advanced. Both have free tiers.
- **[PicoCTF](https://picoctf.org/)**: Capture The Flag competitions designed by Carnegie Mellon University for students. Excellent for beginners.
- **[Practical Networking (YouTube)](https://www.youtube.com/practicalnetworking)**: Deep dives into networking concepts essential for security (Subnetting, OSI model, packets).
