# Data Analysis Path

Turn raw data into insights. Help businesses make decisions based on numbers.

## What You Will Do

- Clean and organize messy datasets.
- Create visualizations and dashboards.
- Perform statistical analysis.
- Present findings to stakeholders.

## Roadmap

### Phase 1: The Basics (Months 1-3)
- **Excel**: Pivot tables, VLOOKUP, formulas.
- **Statistics**: Mean, median, standard deviation, distributions.
- **SQL**: Querying databases (SELECT, JOIN, GROUP BY).
- **Data Visualization**: Charts, graphs, storytelling.

### Phase 2: Programming (Months 4-6)
- **Python**: Pandas, NumPy for data manipulation.
- **Jupyter Notebooks**: Interactive coding environment.
- **Data Cleaning**: Handling missing values, outliers.
- **Exploratory Data Analysis (EDA)**: Finding patterns.

### Phase 3: Advanced Tools (Months 7-9)
- **BI Tools**: Tableau or PowerBI.
- **Machine Learning Basics**: Scikit-learn (optional).
- **Big Data Concepts**: Spark, Hadoop (overview).

## Domain Goodies

- **Kaggle Learn**: Micro-courses on Python, SQL, ML.
- **Google Data Analytics Certificate**: Audit free on Coursera.
- **StatQuest**: YouTube channel for statistics intuition.
- **Mode SQL Tutorial**: Interactive SQL practice.
