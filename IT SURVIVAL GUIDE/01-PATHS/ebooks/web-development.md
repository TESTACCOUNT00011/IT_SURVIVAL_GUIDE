# Web Development Ebooks

## Free & Legal (Community Regarded, Updated)

1. **Eloquent JavaScript** by Marijn Haverbeke
   - Status: Free online (eloquentjavascript.net)
   - Level: Beginner to Intermediate
   - Note: The definitive guide to JS. Third edition is current.

2. **You Don't Know JS Yet** by Kyle Simpson
   - Status: Free on GitHub
   - Level: Intermediate
   - Note: Deep dive into how JS actually works.

3. **Roadmap.sh Guides**
   - Status: Free online
   - Level: All levels
   - Note: Curated checklists for Frontend, Backend, and DevOps.

4. **Full Stack Open** by University of Helsinki
   - Status: Free online
   - Level: Intermediate
   - Note: Modern React, Node.js, and GraphQL course material.

> [!TIP] Reading Strategy
> Do not read cover-to-cover like a novel. Read one chapter, then build a small project using that concept. Return to the book when you get stuck.
