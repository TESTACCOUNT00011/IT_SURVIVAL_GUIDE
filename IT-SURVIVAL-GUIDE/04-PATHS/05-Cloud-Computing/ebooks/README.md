# Cloud Computing Ebooks

## Free & Legal (Community Regarded)

- **AWS Certified Solutions Architect Official Study Guide** (Sample Chapters)
  - Free samples from Wiley/Pearson.
  - Good overview of AWS services.

- **Microsoft Azure Fundamentals (AZ-900) Learning Path**
  - Free online documentation from Microsoft.
  - Comprehensive coverage of Azure basics.

- **Google Cloud Architecture Framework**
  - Free PDF guides from Google.
  - Best practices for GCP.
