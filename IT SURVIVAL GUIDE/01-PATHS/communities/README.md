# 🤝 Path-Specific Communities & Resources

This folder contains dedicated community guides for each career path. While the main [Community section](../00-COMMUNITY/README.md) covers general tech communities, these files dive deep into **niche groups, Discords, subreddits, and local meetups** specific to each domain.

## Why Join Communities?
- **Get Unstuck Faster**: Real humans answer questions when Google fails.
- **Networking**: 70% of jobs are found through connections, not applications.
- **Mentorship**: Find seniors willing to review your code or resume.
- **Trend Awareness**: Learn about new tools before they hit the mainstream.
- **Accountability**: Study groups keep you motivated.

## ⚠️ Community Etiquette (Read Before Joining!)
1. **Search First**: Don't ask questions that were answered 5 minutes ago.
2. **Show Effort**: "I tried X, Y, Z but got error A" gets better help than "Fix this."
3. **No Spam**: Don't DM people selling courses or services immediately.
4. **Give Back**: Once you learn something, help the next newbie.
5. **Stay Safe**: Never share passwords, API keys, or personal info in public channels.
