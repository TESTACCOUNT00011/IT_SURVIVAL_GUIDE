# Welcome to the IT Survival Guide

This guide is designed for absolute beginners. It assumes you know nothing about computers, coding, or technology.

> [!WARNING] Link Rot Warning
> **Links break over time.** The tech industry moves fast, and URLs change. If a link in this guide doesn't work:
> 1. Don't panic.
> 2. Copy the resource name (e.g., "freeCodeCamp", "Roadmap.sh").
> 3. Search for it on Google/YouTube.
> 4. Look for the official website or most recent tutorial.
> 
> The *concepts* in this guide remain valid even if specific links expire.

## Critical Warning: The English Bottleneck

> [!WARNING] Important Language Notice
> The IT and Computer Science industries operate primarily in **English**. 
> - Documentation, error messages, and forums are 90% English.
> - If English is not your strong suit, it will become your biggest bottleneck.
> 
> **Action Required:** 
> 1. Install a translation extension (e.g., Google Translate, DeepL).
> 2. Use AI tools to simplify complex texts (see [[02-English-Support]]).
> 3. Learn technical English vocabulary gradually.

## How to Use This Guide

1. **Start Here**: Read the notes in `01-START-HERE`.
2. **Basics**: Move to `02-BASICS` to learn computer fundamentals.
3. **Toolkit**: Set up your environment in `03-TOOLKIT`.
4. **Choose a Path**: Explore `04-PATHS` when ready to specialize.
5. **Resources**: Use `99-RESOURCES` for flashcards and templates.

## Philosophy: Fail Forward

There are no locked doors here. You are free to explore any section. If you try something advanced and fail, that is part of learning. Read the error, search for the solution, and try again.
