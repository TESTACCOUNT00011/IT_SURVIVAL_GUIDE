# Data Analysis Path

Turn raw data into insights. Help businesses make decisions based on numbers.

## What You Will Do

- Clean and organize messy datasets.
- Create visualizations and dashboards.
- Perform statistical analysis.
- Present findings to stakeholders.

## Roadmap

### Phase 1: The Basics (Months 1-3)
- **Excel**: Pivot tables, VLOOKUP, formulas.
- **Statistics**: Mean, median, standard deviation, distributions.
- **SQL**: Querying databases (SELECT, JOIN, GROUP BY).
- **Data Visualization**: Charts, graphs, storytelling.

### Phase 2: Programming (Months 4-6)
- **Python**: Pandas, NumPy for data manipulation.
- **Jupyter Notebooks**: Interactive coding environment.
- **Data Cleaning**: Handling missing values, outliers.
- **Exploratory Data Analysis (EDA)**: Finding patterns.

### Phase 3: Advanced Tools (Months 7-9)
- **BI Tools**: Tableau or PowerBI.
- **Machine Learning Basics**: Scikit-learn (optional).
- **Big Data Concepts**: Spark, Hadoop (overview).

## Domain Goodies

- **Kaggle Learn**: Micro-courses on Python, SQL, ML.
- **Google Data Analytics Certificate**: Audit free on Coursera.
- **StatQuest**: YouTube channel for statistics intuition.
- **Mode SQL Tutorial**: Interactive SQL practice.

## Practice Projects

Build these projects to solidify your skills and create a portfolio:

### Project 1: Excel Data Dashboard (Weeks 1-3)
**Goal**: Master spreadsheet analysis and visualization.
- Download a real dataset (sales, sports, or public government data)
- Clean the data using Excel functions (REMOVE DUPLICATES, TRIM, IFERROR)
- Create pivot tables to summarize key metrics
- Build interactive charts (bar, line, pie, scatter plots)
- Design a one-page executive dashboard
- Use the [[../../00-TEMPLATES/Project-Tracker|Project Tracker Template]] to document your process

### Project 2: SQL Database Analysis (Weeks 4-6)
**Goal**: Become proficient in database querying.
- Install PostgreSQL or use SQLite (free)
- Import a dataset (e.g., Northwind Traders, Chinook database)
- Write queries to answer business questions:
  - Top 10 customers by revenue
  - Monthly sales trends with YoY comparison
  - Product category performance
  - Customer segmentation analysis
- Create views for recurring reports
- Practice on Mode Analytics SQL Tutorial or LeetCode Database problems

### Project 3: Python Data Cleaning & EDA (Weeks 7-9)
**Goal**: Automate data preparation and exploration.
- Choose a messy dataset from Kaggle (missing values, inconsistent formats)
- Use Pandas to:
  - Handle missing data (imputation, removal strategies)
  - Standardize date formats and categorical values
  - Detect and handle outliers
  - Merge multiple data sources
- Perform Exploratory Data Analysis (EDA):
  - Correlation matrices
  - Distribution plots
  - Group-by aggregations
- Document findings in a Jupyter Notebook with markdown explanations

### Project 4: Interactive BI Dashboard (Weeks 10-12)
**Goal**: Create professional business intelligence reports.
- Choose Tableau Public or Power BI Desktop (both free)
- Connect to a dataset (sales, healthcare, or social data)
- Build an interactive dashboard with:
  - Filters (date range, category, region)
  - KPI cards showing key metrics
  - Trend lines and forecasts
  - Geographic maps (if applicable)
- Publish to Tableau Public or Power BI Service
- Write a case study explaining your design decisions

### Project 5: End-to-End Data Analysis Capstone (Weeks 13-16)
**Goal**: Demonstrate full data analyst workflow.
- Define a business problem or research question
- Acquire data from multiple sources (APIs, CSVs, web scraping)
- Clean and transform data using Python (Pandas, NumPy)
- Perform statistical analysis and hypothesis testing
- Create visualizations and build a dashboard
- Write a comprehensive report with actionable recommendations
- Present findings in a blog post or GitHub README
- Example topics:
  - "Analyzing COVID-19 impact on local businesses"
  - "Predicting customer churn for a telecom company"
  - "Sports analytics: What drives team success?"
