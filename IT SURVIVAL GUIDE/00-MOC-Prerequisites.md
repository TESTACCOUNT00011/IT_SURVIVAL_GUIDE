# Prerequisites: Map of Content

Before choosing a specialized career path, you should understand these core concepts. They apply to **all** IT fields.

## Core Concepts

- [[01-How-Internet-Works|How the Internet Works]]: IP, DNS, HTTP, Servers vs Clients.
- [[02-Command-Line-Basics|Command Line Basics]]: Navigating without a mouse.
- [[03-Basic-Coding-Concepts|Coding Concepts]]: Variables, loops, functions (language agnostic).
- [[04-Git-Version-Control|Git & Version Control]]: Saving and tracking code changes.
- [[05-Hardware-Basics|Hardware Basics]]: CPU, RAM, Storage, GPU.
