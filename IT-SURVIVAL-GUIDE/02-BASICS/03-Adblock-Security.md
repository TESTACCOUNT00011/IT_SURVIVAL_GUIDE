# Ad Blocking and Browser Safety

The modern web is filled with ads, trackers, and malicious pop-ups. You need a clean browser to learn safely.

## The Problem

- **Distraction**: Ads break focus.
- **Malware Risk**: Fake "Download" buttons on ad networks install viruses.
- **Speed**: Trackers slow down page loading.

## The Solution: uBlock Origin

Do not use "AdBlock Plus". Use **uBlock Origin**. It is free, open-source, and lightweight.

### Installation Steps

1. Open your browser (Chrome, Firefox, Edge).
2. Go to the official extension store:
   - Chrome: Chrome Web Store
   - Firefox: Firefox Add-ons
   - Edge: Microsoft Edge Add-ons
3. Search for `uBlock Origin` (by Raymond Hill).
4. Click **Add to Browser**.
5. Confirm installation.

> [!WARNING] Fake Versions
> Only install "uBlock Origin". Avoid "uBlock", "AdBlock Pro", or other clones. They may sell your data.

## Configuration

Once installed:
1. Click the shield icon in your toolbar.
2. Ensure it is enabled (power button on).
3. No extra setup is needed for beginners. It works out of the box.

## Other Essential Extensions

- **Bitwarden**: Free password manager. Never reuse passwords.
- **Dark Reader**: Forces dark mode on all websites to reduce eye strain.
