## ✅ Resume Checklist

Before submitting, verify:

### Content
- [ ] No spelling or grammar errors
- [ ] Consistent formatting throughout
- [ ] All dates are accurate
- [ ] Contact information is current
- [ ] Links work (LinkedIn, GitHub, Portfolio)
- [ ] Quantified achievements where possible
- [ ] Tailored to the specific job posting

### Format
- [ ] Length: 1 page (entry-level) or 2 pages max
- [ ] Font: Professional and readable (10-12pt)
- [ ] Margins: 0.5" - 1"
- [ ] File format: PDF (unless otherwise specified)
- [ ] File name: FirstName_LastName_Resume.pdf

### ATS Optimization
- [ ] Included keywords from job description
- [ ] Simple formatting (no graphics/columns for ATS)
- [ ] Standard section headings
- [ ] No headers/footers (ATS can't read them)

## 💡 Pro Tips

### For Career Changers
- Emphasize transferable skills from previous roles
- Highlight projects and certifications over formal education
- Use a functional or hybrid resume format if needed

### For New Graduates
- Put Education above Experience
- Include relevant coursework and academic projects
- Highlight internships and part-time tech work

### For Self-Taught Developers
- Showcase portfolio projects prominently
- List online courses and bootcamps under Education
- Contribute to open source and include GitHub link

### Action Verbs for IT Resumes
- Developed, Built, Created, Designed, Implemented
- Optimized, Improved, Reduced, Increased, Automated
- Managed, Led, Coordinated, Collaborated
- Analyzed, Diagnosed, Resolved, Troubleshoot
- Deployed, Configured, Maintained, Monitored
