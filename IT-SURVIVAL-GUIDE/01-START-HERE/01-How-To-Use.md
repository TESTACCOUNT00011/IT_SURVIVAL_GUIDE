# How to Use This Guide

This guide is non-linear. You can jump around, but following the suggested order helps avoid confusion.

## The Flow

1. **Read the Welcome**: Understand the philosophy and warnings.
2. **Master the Basics**: Do not skip typing or search skills.
3. **Setup Your Toolkit**: Install essential software safely.
4. **Explore Paths**: Try small tasks from different career paths.
5. **Pick One**: Commit to a path for 3 months before switching.

## Note Format

Each note uses:
- **Frontmatter**: Tags and difficulty ratings at the top.
- **Callouts**: Boxes for warnings, tips, and important info.
- **Wiki Links**: `[[Link]]` connects concepts. Click them to navigate.
- **Task Lists**: `- [ ]` items are challenges for you to complete.

## Using AI Help

If you get stuck:
1. Copy the confusing text.
2. Paste it into an AI chat.
3. Use the prompts in [[02-English-Support]] to simplify or translate.

## Tracking Progress

Use the templates in `99-RESOURCES/Templates` to log what you learn daily. Consistency beats intensity.
