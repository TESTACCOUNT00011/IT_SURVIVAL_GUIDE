# Cybersecurity Ebooks

## Free & Legal (Community Regarded, Updated)

1. **Metasploit: The Penetration Tester's Guide** (Selected Chapters)
   - Status: Free samples and community docs
   - Level: Intermediate
   - Note: Official documentation is extensive.

2. **OWASP Testing Guide**
   - Status: Free PDF (owasp.org)
   - Level: All levels
   - Note: Industry standard for web app security testing.

3. **NIST Cybersecurity Framework**
   - Status: Free PDF (nist.gov)
   - Level: Intermediate to Advanced
   - Note: US government standards, widely adopted.

4. **Security Plus Study Notes** (Various Authors on GitHub)
   - Status: Free on GitHub
   - Level: Beginner
   - Note: Community-maintained exam prep.
