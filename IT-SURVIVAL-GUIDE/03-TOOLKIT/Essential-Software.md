# Essential Toolkit

Software and extensions every beginner needs. Safe and free.

## Browser Extensions

- **uBlock Origin**: Block ads and malicious scripts.
- **Bitwarden**: Password manager. Generate unique passwords for every site.
- **Dark Reader**: Force dark mode on all websites.
- **Wappalyzer**: See what technologies a website uses.

## Core Software

- **VS Code**: Free code editor. Lightweight and powerful.
  - [Windows]: Download installer from `code.visualstudio.com`. Run setup, check "Add to PATH".
  - [Mac]: `brew install --cask visual-studio-code` or drag `.dmg` to Applications.
  - [Linux]: `sudo snap install code --classic` or use your distro's package manager.
- **Git**: Version control.
  - [Windows]: Download from `git-scm.com`. Use default settings in wizard.
  - [Mac]: Install Xcode Command Line Tools (`xcode-select --install`) then `brew install git`.
  - [Linux]: `sudo apt install git` (Debian/Ubuntu) or `sudo dnf install git` (Fedora).
- **Node.js**: JavaScript runtime (needed for many web tools).
  - [Windows/Mac]: Download LTS version from `nodejs.org`.
  - [Linux]: Use NodeSource repository or `nvm` (Node Version Manager).
- **Python 3**: Programming language for scripting and data.
  - [Windows]: Download from `python.org`. **Check "Add Python to PATH"** during install.
  - [Mac]: Pre-installed on older macOS, but recommended to install latest via `brew install python`.
  - [Linux]: Pre-installed on most distros. Update with `sudo apt update && sudo apt upgrade python3`.

## Communication

- **Discord**: For joining tech communities.
  - [Windows/Mac/Linux]: Download from `discord.com` or use web version.
- **Zoom/Google Meet**: For interviews and meetings.
  - [Windows/Mac]: Download desktop app or use browser.
  - [Linux]: Use browser version or `sudo snap install zoom-client`.
- **Slack**: Used by many companies for chat.
  - [Windows/Mac/Linux]: Download from `slack.com` or use web version.

## Safety Rules

1. **Download from Official Sites Only**:
   - Do not click "Download" buttons on random blogs.
   - Go to `code.visualstudio.com`, `git-scm.com`, `python.org`.
2. **Avoid "Cracked" Software**: It often contains malware.
3. **Keep Updated**: Enable auto-updates for security patches.

> [!WARNING] Fake Download Buttons
> Search results often contain ads that look like download links. Look for the actual domain name in the URL.
