# 💻 Path 1: Web Development

**Build websites and web applications that people use every day.**

---

## 🎯 What Do Web Developers Do?

Web developers create everything you see and use on the internet:
- Websites (like blogs, portfolios, business sites)
- Web applications (like Gmail, Trello, Netflix)
- E-commerce stores (like Amazon, Shopify shops)
- Social media platforms (like Twitter, Facebook)

---

## 🔧 Three Main Areas

### 1. Frontend Development
**What users SEE and INTERACT with**

- HTML (structure of web pages)
- CSS (styling and layout)
- JavaScript (interactivity and logic)
- Frameworks like React, Vue, or Angular

**You'll enjoy this if:** You like visual results and user experience

---

### 2. Backend Development
**The server-side logic (what happens behind the scenes)**

- Server programming (Node.js, Python, Ruby, PHP, Java)
- Databases (MySQL, PostgreSQL, MongoDB)
- APIs (how frontend and backend communicate)
- Authentication and security

**You'll enjoy this if:** You like logic, data, and problem-solving

---

### 3. Full-Stack Development
**Both frontend AND backend**

- Everything from frontend + backend
- Understanding how everything connects
- Building complete applications alone

**You'll enjoy this if:** You want versatility and to build complete products

---

## 📚 Learning Roadmap

### Phase 1: Foundations (4-6 weeks)

**Learn these in order:**

1. **HTML Basics**
   - Tags, elements, attributes
   - Forms, tables, semantic HTML
   - Accessibility basics

2. **CSS Basics**
   - Selectors, colors, fonts
   - Box model (margins, padding, borders)
   - Flexbox and Grid (layout systems)
   - Responsive design (mobile-friendly)

3. **JavaScript Basics**
   - Variables, data types, operators
   - Functions, loops, conditionals
   - DOM manipulation (changing web pages dynamically)
   - Events (clicks, form submissions)

✅ **Project:** Build a personal portfolio website (static)

---

### Phase 2: Intermediate Skills (8-12 weeks)

1. **Advanced JavaScript**
   - ES6+ features (arrow functions, destructuring, modules)
   - Async programming (promises, async/await)
   - Fetch API (getting data from servers)

2. **Version Control (Git)**
   - Already covered in Prerequisites! ✅

3. **CSS Frameworks**
   - Bootstrap or Tailwind CSS
   - Speed up styling work

4. **JavaScript Framework (Pick ONE)**
   - **React** (most popular, lots of jobs)
   - **Vue** (easier learning curve)
   - **Angular** (enterprise favorite)

✅ **Project:** Build a dynamic app (todo list, weather app, recipe finder)

---

### Phase 3: Backend Basics (8-12 weeks)

1. **Choose a Backend Language**
   - **Node.js** (JavaScript on the server - recommended for beginners)
   - **Python** (easy syntax, versatile)
   - **Ruby** (beginner-friendly)

2. **Learn a Backend Framework**
   - Express.js (for Node.js)
   - Django or Flask (for Python)
   - Ruby on Rails (for Ruby)

3. **Databases**
   - SQL basics (MySQL or PostgreSQL)
   - OR NoSQL (MongoDB)
   - CRUD operations (Create, Read, Update, Delete)

4. **APIs**
   - RESTful API design
   - Authentication (JWT, OAuth)

✅ **Project:** Build a full-stack app (blog with user accounts, e-commerce site)

---

### Phase 4: Advanced Topics (Ongoing)

- Testing (unit tests, integration tests)
- Deployment (hosting your apps)
- Performance optimization
- Security best practices
- TypeScript (typed JavaScript)
- GraphQL (alternative to REST APIs)
- Serverless architecture

✅ **Project:** Build something complex (social media clone, real-time chat app)

## ✅ How to Know You're Ready

You're ready to apply for jobs when you can:

- Build a responsive website from scratch
- Create a full-stack application with user authentication
- Explain your code and decisions clearly
- Debug problems systematically
- Work with Git confidently
- Show 3-5 solid projects in a portfolio

## 💎 Domain Goodies: Legendary Resources for Web Devs

These are the "Hall of Fame" resources specifically for web development. They are challenging but will change how you see the web.

- **[Harvard CS50x](https://cs50.harvard.edu/x/)**: While general CS, the later weeks focus heavily on Web Programming with Python and JavaScript. Essential for understanding *why* the web works, not just *how*.
- **[The Odin Project](https://www.theodinproject.com/)**: A free, open-source, full-stack curriculum that is community-driven and highly respected. It's hard, but it makes you job-ready.
- **[Full Stack Open](https://fullstackopen.com/en/)**: By the University of Helsinki. A deep dive into modern React, Redux, Node.js, MongoDB, GraphQL, and TypeScript. Free and excellent.
- **[JavaScript.info](https://javascript.info/)**: The most detailed, free online book/tutorial for modern JavaScript. Better than most paid courses.
- **[CSS Battle](https://cssbattle.dev/)**: Gamify your CSS skills. Try to replicate targets with the smallest code possible. Great for "fuck around and find out" learning.
