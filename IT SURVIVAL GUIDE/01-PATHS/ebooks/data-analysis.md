# Data Analysis Ebooks

## Free & Legal (Community Regarded, Updated)

1. **Python for Data Analysis** by Wes McKinney (Creator of Pandas)
   - Status: First edition free online via author
   - Level: Intermediate
   - Note: Written by the creator of the Pandas library.

2. **Think Stats** by Allen B. Downey
   - Status: Free PDF (greenteapress.com)
   - Level: Beginner to Intermediate
   - Note: Statistics for programmers, not mathematicians.

3. **Practical Statistics for Data Science**
   - Status: Free chapters online
   - Level: Intermediate
   - Note: Focus on applicable stats, not theory.

4. **Kaggle Micro-Course Notebooks**
   - Status: Free online
   - Level: All levels
   - Note: Interactive coding notebooks with real data.
