# AI Prompts for Learning

This section contains pre-written prompts to help you use AI tools (like ChatGPT, Claude, Gemini) effectively for learning IT concepts.

## Core Prompts

### 1. Language Bridge
For non-native English speakers.
- **File**: [[00-PROMPTS/01-language-bridge]]
- **Use Case**: Translating complex technical text into simple English and your native language.

### 2. ELI5 Visualizer
For difficult abstract concepts.
- **File**: [[00-PROMPTS/02-eli5-visualizer]]
- **Use Case**: Explaining topics like "DNS" or "Recursion" using ASCII art and simple analogies.

### 3. Code Mentor
For learning to code without just getting the answer.
- **File**: [[00-PROMPTS/03-code-mentor]]
- **Use Case**: Getting hints and guidance instead of full solutions.

### 4. Roadmap Generator
For planning your study.
- **File**: [[00-PROMPTS/04-roadmap-generator]]
- **Use Case**: Creating a week-by-week study plan based on your available time.

### 5. Prompt Libraries
Websites with thousands of community prompts.
- **File**: [[00-PROMPTS/05-prompt-websites]]
- **Use Case**: Finding specialized prompts for specific tools or scenarios.
