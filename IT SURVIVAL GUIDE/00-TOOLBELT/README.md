## 🔒 Browser Extensions Every Tech Person Needs

### Must-Have Extensions
1. **uBlock Origin** - Block ads & trackers (NOT "AdBlock Plus")
2. **Bitwarden** - Auto-fill passwords securely
3. **Dark Reader** - Dark mode for every website
4. **Wappalyzer** - See what tech a website uses
5. **JSON Viewer** - Pretty-print JSON data
6. **React Developer Tools** - Debug React apps (if learning React)
7. **Vue Devtools** - Debug Vue apps (if learning Vue)

### ⚠️ Extensions to AVOID
- Any "Free Netflix" or "Crack" extensions (Malware!)
- Random "PDF Converter" extensions (Data harvesters)
- Extensions not updated in 2+ years
- Extensions with < 10,000 users (Unless from trusted devs)

**Rule:** If an extension asks for "Read and change all your data on all websites," make sure you trust the developer!

## 🚫 "Don't Touch" List: Avoid Malware & Scams

### ❌ Never Download From:
- Torrent sites for paid software (Cracks = Viruses)
- Random Google Ads claiming "Download Now"
- Email attachments from strangers
- Discord DMs sending ".exe" files
- YouTube video descriptions with "free courses" links

### ❌ Never Run Commands You Don't Understand
Especially if they say:
- "Copy paste this to get free [anything]"
- "Run this to unlock premium features"
- `sudo rm -rf` (Deletes everything)
- `curl [sketchy-url] | bash` (Runs random scripts)

### ❌ Red Flags in Software
- No official website
- Only available on third-party download sites (Softonic, CNET Download, etc.)
- Asks for admin access immediately
- Disables your antivirus
- Pop-ups saying "Your PC is infected!"

## 🔐 Security Best Practices for Your Dev Machine

1. **Use a Standard User Account** - Don't use Admin for daily tasks
2. **Enable Firewall** - Windows Defender or macOS Firewall
3. **Auto-Updates On** - Keep OS and browsers updated
4. **Backup Regularly** - Use Google Drive, OneDrive, or external drive
5. **Use SSH Keys** - Not passwords for GitHub/GitLab
6. **Encrypt Your Drive** - BitLocker (Windows) or FileVault (Mac)

## 🧹 Maintenance Tips

- **Monthly:** Check for software updates
- **Weekly:** Clear browser cache & downloads folder
- **Daily:** Close tabs you don't need (Saves RAM!)
- **Every 6 Months:** Review installed programs, uninstall unused ones
