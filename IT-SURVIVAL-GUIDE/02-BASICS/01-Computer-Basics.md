# Computer Basics

Before coding, you must understand the machine you are using.

## Core Components

- **CPU (Processor)**: The brain. It does the calculations.
- **RAM (Memory)**: Short-term memory. Holds data for running programs. Clears when power is off.
- **Storage (HDD/SSD)**: Long-term memory. Saves files permanently.
- **OS (Operating System)**: The manager. Windows, macOS, or Linux. It lets you talk to the hardware.

## File Systems

Files are organized in folders (directories).
- **Windows**: Uses `C:\Users\Name\Documents`. Backslashes `\`.
- **Mac/Linux**: Uses `/home/name/Documents`. Forward slashes `/`.

> [!WARNING] Case Sensitivity
> - Windows: `File.txt` and `file.txt` are the SAME.
> - Mac/Linux: `File.txt` and `file.txt` are DIFFERENT.

## Installing Software

1. **Official Sources Only**: Download from the official website or app store.
2. **Avoid "Download" Buttons**: Ads often look like download buttons. Look for the small real link.
3. **Read Installation Steps**: Uncheck boxes that offer "extra toolbars" or "antivirus trials".
