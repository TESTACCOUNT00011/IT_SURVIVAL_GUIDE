# Search Skills (Google Fu)

## The Most Important Skill
In IT, nobody knows everything. The skill that matters most is knowing how to find answers quickly. This is called "Google Fu".

## Basic Syntax Rules

### Exact Match
Use quotes to find an exact phrase.
- ` "permission denied error" ` finds that exact phrase, not just pages containing "permission" and "denied".

### Exclude Words
Use a minus sign to remove unwanted results.
- ` python speed -snake ` searches for Python programming speed, excluding snake results.

### Site-Specific Search
Search only within a specific website.
- ` site:stackoverflow.com python list index ` finds Python list issues only on StackOverflow.
- ` site:reddit.com best mechanical keyboard ` finds Reddit discussions.

### Filetype Search
Find specific document types.
- ` filetype:pdf networking basics ` finds PDF guides.

## How to Read Error Messages
When you encounter an error:
1. Copy the **entire** error message.
2. Paste it into Google inside quotes.
3. Add the name of the tool/language you are using.
   - Example: `"ModuleNotFoundError: No module named 'flask'" python`

## Evaluating Results
- **Date**: Is the article older than 3 years? It might be outdated.
- **Source**: Prefer official documentation, StackOverflow, or reputable tech blogs.
- **Comments**: Check if others say "this didn't work" in the comments.

## Micro-Challenge
1. Find the official documentation for "Python".
2. Find a StackOverflow thread about "how to center a div".
3. Find a PDF guide on "Linux basics".

> [!TIP] The 20-Minute Rule
> Try to solve a problem yourself for 20 minutes. If stuck, search. If still stuck after searching for 20 minutes, ask for help.
