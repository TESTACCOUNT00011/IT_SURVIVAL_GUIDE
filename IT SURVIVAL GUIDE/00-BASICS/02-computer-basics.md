# 02 - Computer Basics (ELI5 Edition)

## 🖥️ What Even IS a Computer?

A computer is just a **really fast calculator** that can:
- Show you pictures and videos
- Let you talk to people online
- Store your files (photos, documents, etc.)
- Run programs (apps, games, browsers)

That's it. Nothing magical.

---

## 🧩 The Main Parts

### 1. Hardware (Stuff You Can Touch)

| Part | What It Does | Real-Life Comparison |
|------|--------------|---------------------|
| **CPU** (Processor) | Thinks and calculates | The brain |
| **RAM** (Memory) | Holds what you're working on RIGHT NOW | Your desk workspace |
| **Storage** (Hard Drive/SSD) | Stores everything permanently | A filing cabinet |
| **Monitor** | Shows you what's happening | A TV screen |
| **Keyboard & Mouse** | How you talk to the computer | Your hands |

**Simple explanation:** 
- When you open a program, it loads from **Storage** → **RAM** → **CPU** works on it → Shows result on **Monitor**

### 2. Software (Stuff You Can't Touch)

**Operating System (OS)** - The boss of your computer
- **Windows** - Most common, comes with most PCs
- **macOS** - Only on Apple computers
- **Linux** - Free, used by programmers (don't worry about this yet)

**Programs/Apps** - Tools that do specific things
- Web browser (Chrome, Firefox, Edge) - For internet
- Word processor (Word, Google Docs) - For writing
- Media player - For videos/music

---

## 🌐 What's the Internet?

The internet is just **a bunch of computers talking to each other**.

- **Website** = Files stored on someone else's computer (called a "server")
- **Browser** = The app that fetches and shows you those files
- **URL** (the address bar) = The address of where the website lives

**Example:** 
When you type `youtube.com`:
1. Your browser asks: "Where is youtube.com?"
2. Internet says: "It's over at this address!"
3. Browser goes there, grabs the files, and shows you YouTube

## 📁 Files and Folders

**File** = One thing (a document, a photo, a song)
**Folder** = A container for files (like a physical folder)

### Common File Types

| Extension | What It Is | Programs That Open It |
|-----------|------------|----------------------|
| `.txt` | Plain text | Notepad, TextEdit |
| `.docx` | Word document | Microsoft Word |
| `.pdf` | Document (looks same everywhere) | Adobe Reader, Browser |
| `.jpg` / `.png` | Image | Photos app, Browser |
| `.mp4` | Video | VLC, Media Player |
| `.mp3` | Music | Any music player |

## ⚡ Basic Operations Everyone Should Know

### Copy and Paste (YOU WILL USE THIS EVERY DAY)

**Windows:**
- Copy: `Ctrl + C`
- Paste: `Ctrl + V`
- Cut: `Ctrl + X`

**Mac:**
- Copy: `Command + C`
- Paste: `Command + V`
- Cut: `Command + X`

**What's the difference?**
- **Copy** = Duplicate something (original stays)
- **Cut** = Move something (original disappears)
- **Paste** = Put the copied/cut thing somewhere new

### Select All
- `Ctrl + A` (Windows) or `Command + A` (Mac)

### Undo (OH NO I MADE A MISTAKE!)
- `Ctrl + Z` (Windows) or `Command + Z` (Mac)
- This is your BEST FRIEND. Messed up? Press this.

## 🔌 Turning It On and Off

### Starting Up
1. Press the power button (look for ⏻ symbol)
2. Wait (computers are slower when starting)
3. You might need to enter a password
4. You'll see the "Desktop" - this is your main screen

### Shutting Down (DON'T just unplug it!)

**Windows:**
1. Click the Windows button (bottom left)
2. Click the Power icon ⏻
3. Click "Shut down"

**Mac:**
1. Click Apple menu (top left )
2. Click "Shut Down"

**Why not just unplug?** 
Your computer saves stuff while shutting down. Unplugging = possible file damage.

## 🤔 Common Confusing Things

### "The computer is slow!"
Usually means:
- Too many programs open (close some!)
- Not enough storage space (delete old files)
- Computer is old (sad but true)

### "I clicked something and now everything looks weird!"
You probably changed a setting. Don't panic!
- Try pressing `Undo` (Ctrl+Z)
- Or close and reopen the program
- Google what happened (someone else had the same problem!)

### "Where did my file go?!"
Check:
- The Desktop
- Downloads folder
- Documents folder
- Use the search bar (Windows: bottom left, Mac: top right)
