# IT Support Ebooks

## Free & Legal (Community Regarded, Updated)

1. **Automate the Boring Stuff with Python** by Al Sweigart
   - Status: Free online (automatetheboringstuff.com)
   - Level: Beginner
   - Note: Essential for scripting repetitive IT tasks.

2. **CompTIA A+ Study Guides** (Official Objectives)
   - Status: Free PDF from CompTIA
   - Level: Beginner
   - Note: Download exam objectives to know exactly what to study.

3. **The Linux Command Line** by William Shotts
   - Status: Free PDF (linuxcommand.org)
   - Level: Beginner to Intermediate
   - Note: Complete book on using Linux terminal.

4. **Microsoft Learn Documentation**
   - Status: Free online
   - Level: All levels
   - Note: Official guides for Windows Server and Azure.
