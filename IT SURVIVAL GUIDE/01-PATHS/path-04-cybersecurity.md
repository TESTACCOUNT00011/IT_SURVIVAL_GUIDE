# Path 4: Cybersecurity

## What You Will Do
Protect organizations from cyber attacks. Find vulnerabilities before hackers do, respond to incidents, and secure networks and applications. This field requires broad knowledge of IT first.

## Day 1 Challenge
Download "OverTheWire Bandit". Complete Level 0 to Level 3. This teaches basic Linux security commands.

## Learning Roadmap

### Phase 1: IT Foundations (Months 1-3)
**Warning**: Do not skip this. You cannot secure what you do not understand.
- **Networking**: TCP/IP, DNS, HTTP, Ports, Firewalls.
- **Operating Systems**: Linux command line, Windows internals.
- **Basic Scripting**: Python or Bash for automation.
- **Resource**: Professor Messer Network+ videos.

### Phase 2: Security Fundamentals (Months 4-6)
- **Cryptography**: Encryption, hashing, certificates.
- **Threats & Vulnerabilities**: Malware, phishing, exploits.
- **Identity Management**: MFA, SSO, Active Directory.
- **Resource**: TryHackMe "Pre-Security" and "Complete Beginner" paths.

### Phase 3: Hands-On Practice (Months 7-12)
- **Capture The Flag (CTF)**: HackTheBox, TryHackMe rooms.
- **Web Security**: OWASP Top 10 vulnerabilities.
- **Network Scanning**: Nmap, Wireshark.
- **Resource**: PortSwigger Web Security Academy (Free).

### Phase 4: Specialization (Year 2+)
Choose one focus:
- **Penetration Testing**: Ethical hacking.
- **Blue Team**: Defense and incident response.
- **Security Engineering**: Building secure systems.
- **GRC**: Governance, Risk, Compliance (less technical).

## Domain Goodies
- **OverTheWire Bandit**: Free Linux security game.
- **TryHackMe**: Gamified learning paths (free tier available).
- **HackTheBox**: Advanced penetration practice.
- **PicoCTF**: Beginner-friendly CTF competitions.
- **Practical Networking**: Deep-dive networking videos.

## Certifications to Target
- **CompTIA Security+**: Entry-level must-have.
- **eJPT**: Practical junior pen-tester cert.
- **OSCP**: Advanced penetration testing (gold standard).
- **CISSP**: Management level (requires experience).
